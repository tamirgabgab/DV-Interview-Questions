# 0040 — the 1011 sequence detector: the video script

The storyboard of the video: the captions of every beat (Hebrew, a `> ` line per caption
line, a blank line between captions), in the order the video shows them. The captions are
exactly what the video shows; `videos/render.py` fails when scene.py's captions differ.

The answer is hardware, so the code beat types the page's SystemVerilog module (the owner, 2026-11-01: SV in this round, the 0011 exception) and walks it beside the page's box, with no line trace. Part א: the state as "how much of the pattern was seen", the Mealy diagram drawn edge by edge (forward, the self loops, S2 → S0, S3 → S2 for the overlap, S3 → S1 with the output 1), the stream 1011011 stepped on it (detections in cycles 4 and 7), the page's box fed the same bits (`BOXES['stream']`), `seq_detect_1011` typed in a 14-line window then walked beside the box bit by bit, the timing diagram built cycle by cycle with the state register's two bits after each rising edge (the page's WaveDrom diagram), the cost (2 flip-flops, one gate from din to found) and the trap of going back to S0 on a mismatch, shown on 101011 (missed in cycle 6). Part ב: the pattern 10101, the state as a suffix that is a prefix, the pattern slid under the input 1011 to the longest match (S1), the formula with fail, the table of 10101 row by row (the full state behaves as S3), the page's `next_state` shown with its two key lines, the box building 10101 (`BOXES['build']`), Mealy against Moore (S4 with the output; its edges equal S3's in Mealy; on 1011011 the outputs in cycles 4, 7 against 5, 8), the box switched to Moore (`BOXES['mm']`) and the cost.
