# שאלות ראיון עבודה ב-DV

אוסף שאלות מראיונות עבודה בתחום **Design Verification**, ולצידן שאלות מתמטיקה, הסתברות
וחידות היגיון שעולות באותם ראיונות. לכל שאלה ניסוח ברור, פתרון מלא ומוסבר בעברית, קוד
ב-SystemVerilog וב-Python שנבדק אוטומטית, ואיורים במקומות שבהם הם עוזרים.

## מסלולי לימוד

כמה שאלות באותו נושא, בסדר שבו כדאי לפתור אותן. [כל המסלולים](paths/index.md)

<!-- path-cards -->

!!! tip "איך מתאמנים באתר"
    - **בוחרים שאלה** לפי רמה, קושי או נושא בטבלה שלמטה, לפי מסלול לימוד, או בכפתור
      "שאלה אקראית".
    - **מנסים לפתור לבד.** הפתרונות מקופלים; הרמזים נפתחים בהדרגה, מהקל לחזק.
    - **מצב תרגול** בראש כל שאלה מסתיר את הפתרונות ומפעיל שעון עצר. בלוק **"מה
      המראיין בודק"** אפשר לפתוח גם לפני שפותרים, הוא לא חושף את התשובה.
    - **בפתרון** מתחילים מ"תשובה בקצרה", ואז הרעיון, השלבים, הקוד וההוכחה. ליד שורות
      קוד חשובות יש עיגול ממוספר שפותח הסבר.
    - **מסמנים התקדמות :** הכפתורים "פתרתי" ו"מועדף" בראש כל שאלה נשמרים בדפדפן הזה בלבד,
      ומהם מתעדכנים פסי ההתקדמות וסינון "סימון" בטבלה.
    - **הרצה בדפדפן :** בשאלות עם קוד אפשר לשנות את קוד ה-Python ולהריץ אותו בלי להתקין
      כלום.
