# שאלות ראיון עבודה ב-DV

אוסף שאלות מראיונות עבודה בתחום **Design Verification**, כל אחת עם ניסוח ברור ופתרון מלא
ומוסבר, כולל דיאגרמות, דיאגרמות תזמון וקוד לפי הצורך.

השאלות מחולקות לפי **רמת משרה** ולפי **דרגת קושי**, ומסומנות בתגיות נושא.

| רמת משרה | מה בודקים בדרך כלל |
|----------|--------------------|
| [סטודנט](questions/student/index.md) | יסודות לוגיקה ספרתית, HDL בסיסי, מתמטיקה, הסתברות וחידות היגיון |
| [ג'וניור](questions/junior/index.md) | SystemVerilog, יסודות UVM, כתיבת טסטים ו-checkers, פרוטוקולים פשוטים |
| [סניור](questions/senior/index.md) | ארכיטקטורת סביבת אימות, UVM מתקדם, SVA, סגירת כיסוי, דיבאג |
| [סטאף](questions/staff/index.md) | אסטרטגיית אימות, תכנון, מתודולוגיה והובלת צוות |

**דרגות קושי:** 🟢 קל · 🟡 בינוני · 🔴 קשה (ביחס לרמת המשרה).
