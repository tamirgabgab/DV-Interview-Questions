## השאלה

נתון מספר שלם `x` בין 0 ל-999. כותבים אותו **בדיוק עם 3 ספרות**, ומשלימים אפסים משמאל
לפי הצורך (למשל 7 נכתב 007, ו-45 נכתב 045). מהספרות האלה בונים שני מספרים :

- **מהגדול לקטן :** הספרות ממוינות בסדר יורד.
- **מהקטן לגדול :** הספרות ממוינות בסדר עולה.

מחסרים את הקטן מהגדול. אם ההפרש יוצא בדיוק `x`, המספר `x` נקרא **מיוחד**.

| המספר `x` | מהגדול לקטן | מהקטן לגדול | ההפרש | מיוחד? |
|---|---|---|---|---|
| 352 | 532 | 235 | 297 | ✗ |
| 7 | 700 | 007 | 693 | ✗ |
| 45 | 540 | 045 | 495 | ✗ |
| 111 | 111 | 111 | 0 | ✗ |
| 0 | 000 | 000 | 0 | ✓ |

??? interviewer "מה המראיין בודק"
    - **אפסים משלימים :** האם זוכרים ש-7 הוא 007. בלי זה מספרים קטנים מקבלים תוצאה שגויה.
    - **מיון של שלושה איברים :** אפשר בפונקציית מיון של השפה, אבל בשאלה על חומרה מצפים
      לרשת השוואות קבועה, בלי לולאה.
    - **להוכיח, לא רק להריץ :** הלולאה של סעיף ב נותנת את התשובה, אבל המראיין רוצה לשמוע
      למה היא נכונה.
    - **לצמצם את החיפוש :** האם באמת צריך לבדוק את כל 1,000 המספרים, או שההוכחה מצמצמת
      את המועמדים לקומץ?
    - **להכליל :** בסעיף ג, האם המועמד רואה שהכול תלוי בהפרש בין הספרה הגדולה לקטנה,
      ושבבסיס אי-זוגי אין נקודת שבת אלא מחזור.

### סעיף א – לבדוק מספר אחד

כתבו פונקציה שמקבלת את `x` ומחזירה 1 אם הוא מיוחד, ו-0 אחרת.

??? tip "רמז 1"
    איך מפרקים מספר לספרות בלי להמיר אותו למחרוזת? חלוקה ושארית ב-10.

??? tip "רמז 2"
    אחרי שהספרות ממוינות, שני המספרים נבנים מאותן שלוש ספרות : פעם בסדר אחד ופעם בסדר
    ההפוך. אין צורך למיין פעמיים.

??? success "פתרון סעיף א"
    !!! answer "תשובה בקצרה"
        מפרקים לשלוש ספרות (האפסים המשלימים מתקבלים לבד), ממיינים אותן, בונים מהן את
        הגדול ואת הקטן, ומחזירים 1 אם ההפרש שווה ל-`x`.

    <!-- cost: זמן \( O(1) \) -->

    #### הרעיון { .sol-idea }

    שני המספרים בנויים מאותן שלוש ספרות, ולכן מספיק למיין פעם אחת : המספר הגדול הוא
    הספרות בסדר יורד, והקטן הוא אותן ספרות בסדר הפוך.

    #### השלבים { .sol-steps }

    <div class="steps" markdown>

    1. **לפרק :** הספרות הן `x / 100`, `(x / 10) % 10` ו-`x % 10`. האפסים המשלימים
       מתקבלים לבד : עבור 7 יוצא 0, 0, 7.
    2. **למיין :** את שלוש הספרות בסדר יורד, \( a \ge b \ge c \).
    3. **להרכיב :** הגדול הוא \( 100a + 10b + c \) והקטן הוא \( 100c + 10b + a \).
    4. **להשוות :** את ההפרש ל-`x`.

    </div>

    #### הקוד { .sol-code }

    === "SystemVerilog"
        ```systemverilog title="function is_special" hl_lines="6 7 8"
        function automatic bit is_special(int x);
          int a = x / 100, b = (x / 10) % 10, c = x % 10;   // leading zeros come for free (1)
          int largest, smallest;

          // Sort the three digits in descending order: a >= b >= c
          if (a < b) {a, b} = {b, a};   // (2)!
          if (b < c) {b, c} = {c, b};   // (3)!
          if (a < b) {a, b} = {b, a};   // (4)!

          largest  = 100 * a + 10 * b + c;
          smallest = 100 * c + 10 * b + a;   // (5)!
          return largest - smallest == x;
        endfunction
        ```

        1. חלוקה שלמה ושארית מפרקות את `x` לספרות. עבור `x = 7` מתקבל `a = 0`, `b = 0`,
           `c = 7`, בדיוק כמו 007. לא צריך טיפול מיוחד במספרים קטנים.
        2. השוואה־והחלפה ראשונה : אחריה `a >= b`. ההחלפה `{a, b} = {b, a}` היא השמה
           לשרשור, ולכן לא צריך משתנה עזר.
        3. אחרי ההשוואה הזו הספרה הקטנה ביותר מבין השלוש נמצאת ב-`c`.
        4. ההחלפה הראשונה יכלה להתקלקל בשלב 3 (אם `b` קיבל ערך גדול יותר), ולכן מסדרים
           שוב את `a` ו-`b`. שלוש ההשוואות האלה הן רשת מיון (sorting network) לשלושה
           איברים.
        5. אותן ספרות בסדר הפוך. הספרה האמצעית `b` נשארת במקומה בשני המספרים.

        בחומרה שלוש ההשוואות הן מעגל צירופי של שלושה משווים, בלי לולאה.

    === "Python"
        ```python title="is_special"
        def is_special(x: int) -> int:
            digits = sorted(f"{x:03d}")              # three digits, leading zeros included (1)
            smallest = int("".join(digits))           # ascending order
            largest = int("".join(reversed(digits)))  # descending order (2)
            return int(largest - smallest == x)
        ```

        1. ‏`f"{x:03d}"` מרפדת באפסים משמאל לשלוש ספרות, ו-`sorted` על המחרוזת מחזירה
           רשימה של תווים בסדר עולה. מיון של ספרות כתווים זהה למיון שלהן כמספרים, כי כולן
           באותו אורך.
        2. ‏`reversed` הופכת את הסדר העולה ליורד, בלי מיון שני.

    #### סיבוכיות { .sol-cost }

    ‏\( O(1) \) : תמיד שלוש ספרות, שלוש השוואות ושני מספרים להרכיב.

### סעיף ב – לבדוק את כל המספרים

מריצים את הפונקציה על כל המספרים מ-0 עד 999, ושומרים במערך את אלה שהיא מחזירה עבורם 1.
מה יכיל המערך בסוף? הוכיחו.

??? tip "רמז 1"
    כתבו את ההפרש בעזרת הספרות הממוינות \( a \ge b \ge c \). מה קורה לספרת האמצע?

??? tip "רמז 2"
    ההפרש הוא תמיד כפולה של מספר קבוע. כמה כפולות כאלה יש בין 0 ל-999? מספיק לבדוק רק
    אותן.

??? success "פתרון סעיף ב"
    !!! answer "תשובה בקצרה"
        המערך יכיל שני מספרים בלבד : **0 ו-495**.

    <!-- cost: בדיקות 1,000 -->

    #### הרעיון { .sol-idea }

    ספרת האמצע מתבטלת בחיסור, ולכן ההפרש הוא תמיד \( 99(a - c) \) : אחת מעשר כפולות של
    99. מספר מיוחד חייב להיות אחת מהן, ובדיקה של עשרת המועמדים משאירה רק את 0 ואת 495.

    #### הקוד { .sol-code }

    === "SystemVerilog"
        ```systemverilog title="function find_special"
        function automatic void find_special(ref int special[$]);
          special.delete();   // (1)!
          for (int x = 0; x <= 999; x++)
            if (is_special(x)) special.push_back(x);
        endfunction
        ```

        1. התור מגיע מהקורא (`ref`), ולכן מרוקנים אותו קודם : אחרת קריאה שנייה הייתה
           מוסיפה את התוצאות פעם נוספת.

    === "Python"
        ```python title="find_special"
        def find_special() -> list[int]:
            return [x for x in range(1000) if is_special(x)]
        ```

    #### למה זה נכון { .sol-proof }

    <div class="steps" markdown>

    1. **ההפרש תמיד כפולה של 99.** נסמן את הספרות הממוינות \( a \ge b \ge c \). אז :

        \[
        \begin{aligned}
        & (100a + 10b + c) - (100c + 10b + a) \\
        & \quad = 99a - 99c = 99(a - c)
        \end{aligned}
        \]

        ספרת האמצע \( b \) מתבטלת. נסמן \( k = a - c \), ולכן \( 0 \le k \le 9 \).

    2. **המקרה \( k = 0 \).** כל הספרות שוות וההפרש הוא 0. המספר היחיד מהצורה הזו
       שההפרש שלו שווה לו הוא 0 עצמו. למשל 111 נותן הפרש 0, ולא 111.

    3. **הספרות של \( 99k \).** כש-\( 1 \le k \le 9 \), ההפרש הוא

        \[
        99k = 100(k - 1) + 10 \cdot 9 + (10 - k)
        \]

        ולכן הספרות שלו הן \( k - 1 \), ‏9 ו-\( 10 - k \), כולל אפס משלים (עבור \( k = 1 \)
        יוצא 099).

    4. **התנאי ש-`x` שווה להפרש.** אם \( x = 99k \), הספרות של `x` הן אותן ספרות
       \( a, b, c \). הספרה 9 נמצאת ביניהן, והיא הספרה הגדולה ביותר האפשרית, ולכן
       \( a = 9 \) ו-\( c = a - k = 9 - k \). מוציאים את ה-9 משני הצדדים :

        \[
        \{\, b,\; 9 - k \,\} = \{\, k - 1,\; 10 - k \,\}
        \]

        הספרה \( 9 - k \) חייבת להיות אחת משתי הספרות מימין :

        - **‏\( 9 - k = 10 - k \) :** בלתי אפשרי.
        - **‏\( 9 - k = k - 1 \) :** כלומר \( k = 5 \). אז \( b = 10 - k = 5 \), והמספר הוא
          \( x = 99 \cdot 5 = 495 \).

    5. **בדיקה.** הספרות של 495 ממוינות הן 9, 5, 4, ו-\( 954 - 459 = 495 \). ∎

    </div>

    **כל המועמדים בטבלה אחת.** לפי שלב 1, רק עשרה מספרים יכולים להיות מיוחדים :
    \( 0, 99, 198, \ldots, 891 \). הנה תשעת המועמדים שאינם 0 :

    | ‏\( k \) | המספר \( 99k \) | מהגדול לקטן | מהקטן לגדול | ההפרש | מיוחד? |
    |---|---|---|---|---|---|
    | 1 | 099 | 990 | 099 | 891 | ✗ |
    | 2 | 198 | 981 | 189 | 792 | ✗ |
    | 3 | 297 | 972 | 279 | 693 | ✗ |
    | 4 | 396 | 963 | 369 | 594 | ✗ |
    | 5 | 495 | 954 | 459 | **495** | ✓ |
    | 6 | 594 | 954 | 459 | 495 | ✗ |
    | 7 | 693 | 963 | 369 | 594 | ✗ |
    | 8 | 792 | 972 | 279 | 693 | ✗ |
    | 9 | 891 | 981 | 189 | 792 | ✗ |

    שימו לב שהשורות של \( k \) ו-\( 10 - k \) מכילות את אותן ספרות, ולכן נותנות את אותו
    הפרש. רק ב-\( k = 5 \) השורה מתאימה לעצמה.

    **המפה של \( k \).** אותה טבלה אומרת לאן כל \( k \) הולך. ההפרש של \( 99k \) הוא
    \( 99k' \), כי הספרה הגדולה שלו היא 9 והקטנה היא הקטנה מבין \( k - 1 \) ו-\( 10 - k \)
    (שלב 3) :

    \[
    k' = 9 - \min(k - 1,\; 10 - k) = \max(10 - k,\; k - 1)
    \]

    בתיבה הבאה \( k \) נקרא \( d \), כמו בסעיף ג. המפה מציירת חץ מכל \( d \) ל-\( d' \), והמסלול
    של המספר מודגש : 352 נותן \( k = 3 \), ומשם <span dir="ltr">3 → 7 → 6 → 5</span>. רק 5
    מצביע על עצמו, ולכן כל שרשרת שלא נופלת ל-0 נגמרת ב-495.

    <div class="explorer" data-kind="kapbase" data-b="10" data-x="352" data-fixed></div>

    **נסו בעצמכם.** הקלידו מספר או הגרילו אחד : הטבלה מראה את המיון ואת החיסור, ואז
    מפעילים את אותו צעד על ההפרש שוב ושוב. חוץ ממספרים שכל הספרות שלהם שוות (שנופלים ל-0),
    כולם מגיעים ל-495 ונעצרים שם, וההיסטוגרמה מראה אחרי כמה צעדים.

    <div class="explorer" data-kind="kaprekar" data-digits="3"></div>

    #### סיבוכיות { .sol-cost }

    הלולאה בודקת 1,000 מספרים, כל אחד ב-\( O(1) \). לפי ההוכחה אפשר לבדוק רק את עשר
    הכפולות של 99, אבל בראיון הלולאה המלאה היא התשובה המצופה לקוד, וההוכחה היא התשובה
    המצופה לשאלה "מה יכיל המערך".

### סעיף ג – שלוש ספרות בבסיס b { #base-b }

אותו תהליך, אבל המספר כתוב **בבסיס \( b \)** (\( 2 \le b \le 16 \)), עם שלוש ספרות
ואפסים משלימים משמאל. ממיינים את הספרות מהגדול לקטן ומהקטן לגדול ומחסרים :
\( F(X) = \) (הממוין יורד) \( - \) (הממוין עולה). לאילו \( X \) מתקיים \( F(X) = X \), ומה
קורה כשמפעילים את \( F \) שוב ושוב? נסחו את התשובה כפונקציה של \( b \) והוכיחו.

??? tip "רמז 1"
    חזרו על שלב 1 של ההוכחה בסעיף ב עם \( b \) במקום 10 : הספרה האמצעית מתבטלת, וההפרש
    הוא \( d \cdot (b^2 - 1) \) עם \( d \) ההפרש בין הספרה הגדולה לקטנה.

??? tip "רמז 2"
    כתבו את \( d (b^2 - 1) \) בבסיס \( b \) : \( (d - 1) b^2 + (b - 1) b + (b - d) \). שלוש
    הספרות של התוצאה תלויות רק ב-\( d \), ולכן גם ה-\( d \) הבא תלוי רק ב-\( d \).

??? tip "רמז 3"
    ה-\( d \) הבא הוא \( \max(b - d, d - 1) \). לאן המפה הזו דוחפת את \( d \)? מה קורה
    כש-\( b \) זוגי, ומה כשהוא אי-זוגי?

??? success "פתרון סעיף ג"
    !!! answer "תשובה בקצרה"
        ‏**בסיס זוגי :** נקודת שבת יחידה, עם הספרות \( (b/2 - 1,\; b - 1,\; b/2) \) וערך
        \( (b/2)(b^2 - 1) \); בבסיס 10 זה 495. **בסיס אי-זוגי :** אין נקודת שבת אלא מחזור
        באורך 2, בין \( d = (b - 1)/2 \) ל-\( d = (b + 1)/2 \) : הספרות
        \( ((b - 3)/2,\; b - 1,\; (b + 1)/2) \) ו-\( ((b - 1)/2,\; b - 1,\; (b - 1)/2) \). כל
        מספר שלא כל ספרותיו שוות מגיע לשם (מספר עם ספרות שוות נופל ל-0).

    <!-- cost: צעדים \( \lfloor b / 2 \rfloor + 1 \) | בדיקה \( b^3 \) -->

    #### הרעיון { .sol-idea }

    **הכול תלוי ב-d.** עם ספרות ממוינות \( a \ge m \ge c \) ו-\( d = a - c \) :

    \[
    \begin{aligned}
    F(X) &= (a b^2 + m b + c) - (c b^2 + m b + a) \\
         &= d \, (b^2 - 1),
    \end{aligned}
    \]

    וכש-\( 1 \le d \le b - 1 \) :

    \[
    d \, (b^2 - 1) = (d - 1) \, b^2 + (b - 1) \, b + (b - d).
    \]

    שלושת המקדמים בין 0 ל-\( b - 1 \), והייצוג בבסיס \( b \) יחיד, ולכן **הספרות של
    \( F(X) \) הן תמיד \( (d - 1,\; b - 1,\; b - d) \)**. הספרה הגדולה היא \( b - 1 \),
    הקטנה היא \( \min(d - 1, b - d) \), ולכן ה-\( d \) הבא הוא

    \[
    d' = \max(b - d,\; d - 1).
    \]

    זו מפה על המספרים \( 1, \dots, b - 1 \) שדוחפת את \( d \) לאמצע, \( b / 2 \) : כש-\( d \)
    גדול מהאמצע הוא יורד באחד, וכשהוא קטן ממנו הוא קופץ לצד השני ואז יורד. (אם \( d = 0 \)
    כל הספרות שוות, \( F(X) = 0 \), ו-0 הוא נקודת שבת טריוויאלית.)

    **בסיס זוגי.** ‏\( d = b/2 \) היא נקודת שבת של המפה (\( \max(b/2, b/2 - 1) = b/2 \)),
    ולכן המספר עם הספרות \( (b/2 - 1, b - 1, b/2) \) חוזר לעצמו : בבסיס 10 זה 495, ובבסיס 2
    זה 011 (כן, עם אפס משלים).

    <!-- gen 0 -->

    | הבסיס b | ‏d = b / 2 | נקודת השבת בבסיס b | הערך העשרוני |
    |:-:|:-:|:-:|:-:|
    | ‏2 | ‏1 | ‏**011** | ‏3 |
    | ‏4 | ‏2 | ‏**132** | ‏30 |
    | ‏6 | ‏3 | ‏**253** | ‏105 |
    | ‏8 | ‏4 | ‏**374** | ‏252 |
    | ‏10 | ‏5 | ‏**495** | ‏495 |
    | ‏12 | ‏6 | ‏**5B6** | ‏858 |
    | ‏14 | ‏7 | ‏**6D7** | ‏1,365 |
    | ‏16 | ‏8 | ‏**7F8** | ‏2,040 |

    <!-- /gen -->

    **בסיס אי-זוגי.** האמצע \( b/2 \) אינו שלם, ו-\( d \) מתנדנד בין \( k \) ל-\( k + 1 \)
    עם \( b = 2k + 1 \) : \( \max(k + 1, k - 1) = k + 1 \) ו-\( \max(k, k) = k \). שני
    המספרים נבדלים בדיוק ב-\( b^2 - 1 \) :

    <!-- gen 1 -->

    | הבסיס b | ‏d במחזור | המחזור בבסיס b | הערכים העשרוניים |
    |:-:|:-:|:-:|:-:|
    | ‏3 | ‏1 ↔ 2 | ‏**022** ↔ **121** | ‏8 ↔ 16 |

    === "SystemVerilog"
        ```systemverilog title="kaprekar_step_b, kaprekar_attractor_b" hl_lines="3 4 7 8"
        // One step in base b: three digits (leading zeros kept), sorted descending minus ascending.
        function automatic int kaprekar_step_b(int x, int b);
          int a = x / (b * b), m = (x / b) % b, c = x % b;   // (1)!
          if (a < m) {a, m} = {m, a};
          if (m < c) {m, c} = {c, m};
          if (a < m) {a, m} = {m, a};
          return (a * b * b + m * b + c) - (c * b * b + m * b + a);   // (2)!
        endfunction

        // Where every number with two different digits ends: the fixed point of an even base
        // (returns 1, in x1), the two values of the cycle of an odd base (returns 2, in x1 and x2).
        function automatic int kaprekar_attractor_b(int b, output int x1, output int x2);
          int k = b / 2;
          x1 = k * (b * b - 1);                                      // (3)!
          x2 = (k + 1) * (b * b - 1);
          return (b % 2 == 0) ? 1 : 2;
        endfunction
        ```

           כלומר אפס משלים.

    === "Python"
        ```python title="kaprekar_step_b, kaprekar_attractor_b, kaprekar_chain_b"
        def kaprekar_step_b(x: int, b: int) -> int:
            """One step in base b: three digits (leading zeros kept), sorted descending minus ascending."""
            lo, mid, hi = sorted((x // (b * b), x // b % b, x % b))     # (1)!
            return (hi * b * b + mid * b + lo) - (lo * b * b + mid * b + hi)


        def kaprekar_attractor_b(b: int) -> list[int]:
            """Where every number with two different digits ends: the fixed point of an even base,
            the two values of the cycle of an odd one."""
            k = b // 2
            return [k * (b * b - 1)] if b % 2 == 0 else [k * (b * b - 1), (k + 1) * (b * b - 1)]


        def kaprekar_chain_b(x: int, b: int) -> list[int]:
            """The values from x until one of them is in the attractor (or 0)."""
            out = [x]
            while out[-1] != 0 and out[-1] not in kaprekar_attractor_b(b):
                out.append(kaprekar_step_b(out[-1], b))                   # (2)!
            return out
        ```

        1. ‏`sorted` של שלוש הספרות; `lo` ו-`hi` בונים את שני המספרים, ו-`mid` משותף.
        2. השרשרת נעצרת ברגע שנכנסים ליעד : בבסיס אי-זוגי זה אחד משני ערכי המחזור, ומשם
           מתנדנדים לנצח.

    #### למה זה נכון { .sol-proof }

    **נקודת שבת קיימת אם ורק אם \( b \) זוגי.** נניח \( F(X) = X \) עם \( d \ge 1 \). אז
    קבוצת הספרות של \( X \) היא \( \{ d - 1,\; b - 1,\; b - d \} \). הספרה הגדולה ביותר היא
    \( b - 1 \), ולכן \( a = b - 1 \) ו-\( c = a - d = b - 1 - d \). הספרה \( c \) חייבת
    להיות אחת משתי האחרות :

    - **‏\( c = b - d \) :** ‏\( b - 1 - d = b - d \) נותן \( -1 = 0 \), סתירה.
    - **‏\( c = d - 1 \) :** ‏\( b - 1 - d = d - 1 \) נותן \( b = 2d \).

    לכן נקודת שבת קיימת רק כש-\( b \) זוגי, והיא יחידה, \( d = b / 2 \). ∎

    **ההתכנסות.** נסמן \( e = d - b/2 \). אם \( e \ge 1 \) : \( d' = d - 1 \), ו-\( e \) יורד
    באחד. אם \( e \le -1 \) : \( d' = b - d \), ו-\( e \) הופך ל-\( |e| \) (בבסיס אי-זוגי
    \( e \) הוא חצי-שלם, ו-\( |e| = 1/2 \) הוא המחזור). לכן אין מחזורים אחרים, והשרשרת
    הארוכה ביותר מתחילה ב-\( d = 1 \) : צעד אחד ל-\( d = b - 1 \), ואז ירידה של אחד בכל
    צעד עד היעד, בסך הכול \( \lfloor b / 2 \rfloor + 1 \) צעדים ל-\( b \ge 4 \) (6 בבסיס 10, למשל
    \( 100 \to 099 \to 891 \to 792 \to 693 \to 594 \to 495 \)). הציור מראה את
    המפה בבסיס 10 (הכול זורם ל-5) ובבסיס 7 (הכול זורם למחזור 3 ↔ 4), עם המסלול של
