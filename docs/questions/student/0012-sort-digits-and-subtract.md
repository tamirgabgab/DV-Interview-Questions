## השאלה

נתון מספר שלם `x` בין 0 ל-999. כותבים אותו **בדיוק עם 3 ספרות**, ומשלימים אפסים משמאל
לפי הצורך (למשל 7 נכתב 007, ו-45 נכתב 045). מהספרות האלה בונים שני מספרים:

- **מהגדול לקטן:** הספרות ממוינות בסדר יורד.
- **מהקטן לגדול:** הספרות ממוינות בסדר עולה.

מחסרים את הקטן מהגדול. אם ההפרש יוצא בדיוק `x`, המספר `x` נקרא **מיוחד**.

| המספר `x` | מהגדול לקטן | מהקטן לגדול | ההפרש | מיוחד? |
|---|---|---|---|---|
| 352 | 532 | 235 | 297 | ✗ |
| 7 | 700 | 007 | 693 | ✗ |
| 45 | 540 | 045 | 495 | ✗ |
| 111 | 111 | 111 | 0 | ✗ |
| 0 | 000 | 000 | 0 | ✓ |

### סעיף א – לבדוק מספר אחד

כתבו פונקציה שמקבלת את `x` ומחזירה 1 אם הוא מיוחד, ו-0 אחרת.

??? tip "רמז"
    קודם מפרקים את `x` לשלוש ספרות בעזרת חלוקה ושארית ב-10. אחרי שהספרות ממוינות, שני
    המספרים נבנים מאותן שלוש ספרות, פעם בסדר אחד ופעם בסדר ההפוך.

??? success "פתרון סעיף א"
    #### הרעיון: לפרק, למיין, להרכיב ולהשוות

    - **לפרק:** הספרות הן `x / 100`, `(x / 10) % 10` ו-`x % 10`. האפסים המשלימים
      מתקבלים לבד: עבור 7 יוצא 0, 0, 7.
    - **למיין:** את שלוש הספרות בסדר יורד, \( a \ge b \ge c \).
    - **להרכיב:** הגדול הוא \( 100a + 10b + c \) והקטן הוא \( 100c + 10b + a \).
    - **להשוות:** את ההפרש ל-`x`.

    === "SystemVerilog"
        ```systemverilog
        function automatic bit is_special(int x);
          int a = x / 100, b = (x / 10) % 10, c = x % 10;   // leading zeros come for free
          int largest, smallest;

          // Sort the three digits in descending order: a >= b >= c
          if (a < b) {a, b} = {b, a};
          if (b < c) {b, c} = {c, b};
          if (a < b) {a, b} = {b, a};

          largest  = 100 * a + 10 * b + c;
          smallest = 100 * c + 10 * b + a;
          return largest - smallest == x;
        endfunction
        ```

        שלוש ההשוואות הן רשת מיון (sorting network) קטנה: הראשונה מסדרת את `a` ו-`b`,
        השנייה מורידה את הספרה הקטנה ביותר ל-`c`, והשלישית מסדרת שוב את `a` ו-`b`. ההחלפה
        `{a, b} = {b, a}` לא צריכה משתנה עזר. בחומרה זה מעגל צירופי של שלושה משווים, בלי
        לולאה.

    === "Python"
        ```python
        def is_special(x: int) -> int:
            digits = sorted(f"{x:03d}")              # three digits, leading zeros included
            smallest = int("".join(digits))           # ascending order
            largest = int("".join(reversed(digits)))  # descending order
            return int(largest - smallest == x)
        ```

    #### סיבוכיות

    \( O(1) \): תמיד שלוש ספרות, שלוש השוואות ושני מספרים להרכיב.

### סעיף ב – לבדוק את כל המספרים

מריצים את הפונקציה על כל המספרים מ-0 עד 999, ושומרים במערך את אלה שהיא מחזירה עבורם 1.
מה יכיל המערך בסוף? הוכיחו.

??? tip "רמז"
    כתבו את ההפרש בעזרת הספרות הממוינות \( a \ge b \ge c \). מה קורה לספרת האמצע?

??? success "פתרון סעיף ב"
    #### התשובה

    המערך יכיל שני מספרים בלבד: **0 ו-495**.

    === "SystemVerilog"
        ```systemverilog
        function automatic void find_special(ref int special[$]);
          special.delete();
          for (int x = 0; x <= 999; x++)
            if (is_special(x)) special.push_back(x);
        endfunction
        ```

    === "Python"
        ```python
        def find_special() -> list[int]:
            return [x for x in range(1000) if is_special(x)]
        ```

    #### ההוכחה

    **שלב 1: ההפרש תמיד כפולה של 99.**
    נסמן את הספרות הממוינות \( a \ge b \ge c \). אז:

    \[
    (100a + 10b + c) - (100c + 10b + a) = 99a - 99c = 99(a - c)
    \]

    ספרת האמצע \( b \) מתבטלת. נסמן \( k = a - c \), ולכן \( 0 \le k \le 9 \).

    **שלב 2: המקרה \( k = 0 \).**
    כל הספרות שוות וההפרש הוא 0. המספר היחיד מהצורה הזו שההפרש שלו שווה לו הוא 0 עצמו.
    למשל 111 נותן הפרש 0, ולא 111.

    **שלב 3: הספרות של \( 99k \).**
    כש-\( 1 \le k \le 9 \), ההפרש הוא

    \[
    99k = 100(k - 1) + 10 \cdot 9 + (10 - k)
    \]

    ולכן הספרות שלו הן \( k - 1 \), ‏9 ו-\( 10 - k \), כולל אפס משלים (עבור \( k = 1 \)
    יוצא 099).

    **שלב 4: התנאי ש-`x` שווה להפרש.**
    אם \( x = 99k \), הספרות של `x` הן אותן ספרות \( a, b, c \). הספרה 9 נמצאת ביניהן, והיא
    הספרה הגדולה ביותר האפשרית, ולכן \( a = 9 \) ו-\( c = a - k = 9 - k \). מוציאים את ה-9
    משני הצדדים:

    \[
    \{\, b,\; 9 - k \,\} = \{\, k - 1,\; 10 - k \,\}
    \]

    הספרה \( 9 - k \) חייבת להיות אחת משתי הספרות מימין:

    - **‏\( 9 - k = 10 - k \):** בלתי אפשרי.
    - **‏\( 9 - k = k - 1 \):** כלומר \( k = 5 \). אז \( b = 10 - k = 5 \), והמספר הוא
      \( x = 99 \cdot 5 = 495 \).

    **בדיקה:** הספרות של 495 ממוינות הן 9, 5, 4, ו-\( 954 - 459 = 495 \). ∎

    #### כל המועמדים בטבלה אחת

    לפי שלב 1, רק עשרה מספרים יכולים להיות מיוחדים: \( 0, 99, 198, \ldots, 891 \). הנה
    תשעת המועמדים שאינם 0:

    | ‏\( k \) | המספר \( 99k \) | מהגדול לקטן | מהקטן לגדול | ההפרש | מיוחד? |
    |---|---|---|---|---|---|
    | 1 | 099 | 990 | 099 | 891 | ✗ |
    | 2 | 198 | 981 | 189 | 792 | ✗ |
    | 3 | 297 | 972 | 279 | 693 | ✗ |
    | 4 | 396 | 963 | 369 | 594 | ✗ |
    | 5 | 495 | 954 | 459 | **495** | ✓ |
    | 6 | 594 | 954 | 459 | 495 | ✗ |
    | 7 | 693 | 963 | 369 | 594 | ✗ |
    | 8 | 792 | 972 | 279 | 693 | ✗ |
    | 9 | 891 | 981 | 189 | 792 | ✗ |

    שימו לב שהשורות של \( k \) ו-\( 10 - k \) מכילות את אותן ספרות, ולכן נותנות את אותו
    הפרש. רק ב-\( k = 5 \) השורה מתאימה לעצמה.

## נקודות חשובות ושאלות המשך

??? note "נקודות שהמראיין מחפש"
    - **אפסים משלימים:** לזכור ש-7 הוא 007. בלי זה מספרים קטנים מקבלים תוצאה שגויה.
    - **מיון של שלושה איברים:** אפשר בפונקציית מיון של השפה, אבל שלוש השוואות מספיקות.
      בשאלה על חומרה זו התשובה הצפויה.
    - **להוכיח, לא רק להריץ:** הלולאה של סעיף ב נותנת את התשובה, אבל המראיין רוצה לשמוע
      למה. המפתח הוא ש-\( b \) מתבטלת וההפרש תמיד \( 99(a - c) \).
    - **לצמצם את החיפוש:** מתוך ההוכחה, מספיק לבדוק 10 כפולות של 99 במקום 1,000 מספרים.

??? note "שאלות המשך"
    - **לחזור על התהליך:** מתחילים ממספר שלא כל הספרות שלו שוות, ומפעילים שוב ושוב את
      "ממיינים ומחסרים" על התוצאה. תמיד מגיעים ל-495, ולכל היותר אחרי 6 צעדים. למשל
      \( 352 \to 297 \to 693 \to 594 \to 495 \).
    - **ארבע ספרות:** המספרים המיוחדים הם 0 ו-6174 (הקבוע של Kaprekar), ומכל מספר שלא כל
      הספרות שלו שוות מגיעים ל-6174 תוך 7 צעדים לכל היותר.
    - **שתי ספרות:** רק 0 מיוחד. כל מספר אחר נכנס למעגל
      \( 09 \to 81 \to 63 \to 27 \to 45 \to 09 \).
    - **בחומרה:** כתבו מודול צירופי שמקבל 3 ספרות BCD ומוציא את ההפרש. כמה משווים
      וכמה מחסרים צריך?
