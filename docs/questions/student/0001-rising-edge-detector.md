## השאלה

נתון אות `sig` שמסונכרן לשעון `clk`. תכנן מעגל שמוציא במוצא `pulse` פולס ברוחב
**מחזור שעון אחד בדיוק** בכל פעם ש-`sig` עובר מ-`0` ל-`1` (עליית שפה).

יש לשרטט את המעגל, לכתוב אותו ב-SystemVerilog ולצייר דיאגרמת תזמון.

??? interviewer "מה המראיין בודק"
    - **זיכרון במעגל סינכרוני :** האם מבינים ש"שינוי" הוא השוואה בין שני מחזורים, ולכן
      מעגל צירופי בלבד לא מספיק.
    - **רוחב הפולס :** האם המוצא באמת נמשך מחזור אחד בדיוק, גם כש-`sig` נשאר גבוה הרבה
      מחזורים.
    - **דיאגרמת תזמון :** האם יודעים לצייר נכון מתי כל אות משתנה ביחס לעליית השעון, ולא רק
      לכתוב קוד.
    - **איפוס :** מה ערך ההתחלה של הזיכרון, ומה קורה אם `sig` כבר גבוה כשהאיפוס משתחרר.
    - **סגנון RTL :** הפרדה בין לוגיקה רשומה (`always_ff`) ללוגיקה צירופית (`assign`).

---

??? tip "רמז 1"
    פולס ברוחב מחזור אחד בדיוק אומר שהמוצא תלוי לא רק בערך של `sig` עכשיו, אלא גם במה
    שהיה לפני כן. איזה מידע על `sig`, מעבר לערכו הנוכחי, המעגל חייב להחזיק?

??? tip "רמז 2"
    כדי לזהות *שינוי* צריך להשוות בין הערך הנוכחי של האות לבין הערך שלו במחזור הקודם.
    איזה רכיב זוכר ערך של מחזור אחד אחורה?

??? success "פתרון"
    !!! answer "תשובה בקצרה"
        שומרים את `sig` של המחזור הקודם ב-Flip-Flop אחד (`sig_q`), והמוצא הוא **`pulse = sig & ~sig_q`** :
        גבוה בדיוק במחזור שבו `sig` כבר `1` אבל `sig_q` עדיין `0`.

    <!-- cost: פלופים 1 | שערים 2 | השהיה שער אחד -->

    #### הרעיון { .sol-idea }

    שומרים את הערך של `sig` מהמחזור הקודם ב-Flip-Flop אחד, ונקרא לו `sig_q`.
    עליית שפה מתרחשת בדיוק כאשר הערך הנוכחי הוא `1` והערך הקודם היה `0` :

    \[
    pulse = sig \land \lnot sig\_q
    \]

    **המעגל.** Flip-Flop אחד, שער NOT אחד ושער AND אחד :

    ```mermaid
    flowchart LR
        sig([sig]) --> FF["D-FF"]
        clk([clk]) --> FF
        FF -- sig_q --> INV["NOT"]
        sig --> AND["AND"]
        INV --> AND
        AND --> pulse([pulse])
    ```

    #### השלבים { .sol-steps }

    <div class="steps" markdown>

    1. **לזכור :** Flip-Flop מסוג D דוגם את `sig` בכל עליית שעון, ולכן המוצא שלו `sig_q` הוא
       הערך של `sig` במחזור הקודם.
    2. **להשוות :** עליית שפה היא הצירוף "עכשיו `1`, קודם `0`", כלומר `sig & ~sig_q`.
    3. **לאפס :** ב-reset מאפסים את `sig_q` ל-`0`, כדי שלמעגל יהיה ערך התחלה ידוע.

    </div>

    #### הקוד { .sol-code }

    ```systemverilog title="module rise_detect" hl_lines="11 13"
    module rise_detect (
      input  logic clk,
      input  logic rst_n,
      input  logic sig,
      output logic pulse
    );
      logic sig_q;   // (1)!

      always_ff @(posedge clk or negedge rst_n)
        if (!rst_n) sig_q <= 1'b0;   // (2)!
        else        sig_q <= sig;

      assign pulse = sig & ~sig_q;   // (3)!
    endmodule
    ```

    1. כל הזיכרון של המעגל : ביט אחד שמחזיק את `sig` של המחזור הקודם. בלי הביט הזה אין
       דרך להבדיל בין "`sig` עלה עכשיו" לבין "`sig` גבוה כבר הרבה זמן".
    2. ערך ההתחלה חשוב : אם `sig_q` מתחיל ב-`0` ו-`sig` כבר גבוה כשהאיפוס משתחרר, המעגל
       יוציא פולס אחד, כאילו הייתה עליית שפה. אם זו לא ההתנהגות הרצויה, מאפסים ל-`1` או
       מסננים את המחזור הראשון.
    3. המוצא צירופי : הוא משתנה מיד כש-`sig` עולה, ויורד בעליית השעון הבאה, כש-`sig_q`
       הופך ל-`1`. כך רוחב הפולס הוא מחזור אחד בדיוק, בלי קשר לכמה זמן `sig` נשאר גבוה.

    #### למה זה נכון { .sol-proof }

    **דיאגרמת תזמון.** בכל עליית שעון `sig_q` מקבל את הערך של `sig`, ולכן `sig_q` הוא
    עותק של `sig` המאוחר במחזור אחד :

    ```wavedrom
    { signal: [
      { name: "clk",   wave: "p........." },
      { name: "sig",   wave: "0.1...0.1." },
      { name: "sig_q", wave: "0..1...0.1" },
      { name: "pulse", wave: "0.10....10" }
    ]}
    ```

    הפולס עולה באותו מחזור שבו `sig` עולה, ויורד במחזור הבא, כאשר `sig_q` כבר "תפס" את הערך `1`.

    **למה בדיוק מחזור אחד.** במחזור שבו `sig` עולה מתקיים `sig = 1` ו-`sig_q = 0`, ולכן
    `pulse = 1`. בעליית השעון הבאה `sig_q` הופך ל-`1`, ומאותו רגע `~sig_q = 0` וה-AND
    מאפס את `pulse`, גם אם `sig` נשאר גבוה. כש-`sig` יורד, `sig = 0` מאפס את ה-AND מיד,
    ולכן ירידת שפה לא מייצרת פולס.

    **לנסות בעצמכם.** בתיבה הבאה מציירים את `sig` מחזור אחרי מחזור, והמעגל מצייר מתחתיו
    את `sig_q` ואת `pulse`. אפשר לבחור איזו שפה מזהים (עלייה, ירידה או שתיהן, כמו בשאלות
    ההמשך), ולהדליק את המלכודת של האיפוס : `sig` שכבר גבוה כשהאיפוס משתחרר. "העתקת
    WaveDrom" מתחת לרצועה מעתיקה אותה כ-JSON כמו הדיאגרמה שלמעלה, ו"פתיחה בעורך" פותחת
    אותה באתר של WaveDrom.

    <div class="explorer" data-kind="edge"></div>

    #### סיבוכיות { .sol-cost }

    עלות בחומרה : Flip-Flop אחד, שער NOT אחד ושער AND אחד, בלי מונים ובלי מכונת מצבים.
    הנתיב הצירופי מהקלט למוצא הוא שער אחד בלבד, ולכן המעגל לא מגביל את תדר השעון.

## נקודות חשובות ושאלות המשך

??? trap "מלכודת : לזהות שפה עם `@(posedge sig)`"
    לכתוב `always @(posedge sig)` נראה כמו הדרך הישירה "לתפוס עליית שפה", אבל זה הופך את
    `sig` לשעון : מקבלים דומיין שעון נוסף, אין דרך פשוטה לייצר ממנו פולס ברוחב מחזור של
    `clk`, וכלי הסינתזה יתייחסו לזה בהתאם. במעגל סינכרוני דוגמים את `sig` עם `clk`
    ומשווים בין שתי דגימות.

??? trap "מלכודת : אות אסינכרוני"
    אם `sig` מגיע מדומיין שעון אחר, קודם מעבירים אותו דרך סנכרון של שני Flip-Flops
    (2-FF synchronizer), ורק אחר כך מבצעים את זיהוי השפה על האות המסונכרן. זיהוי שפה ישירות
    על אות אסינכרוני עלול לייצר פולסים כפולים או חסרים בגלל metastability.

??? followup "שאלות המשך"
    - **ירידת שפה :** מחליפים את התנאי ל-`~sig & sig_q`.
    - **שתי השפות :** משתמשים ב-`sig ^ sig_q` (XOR).
    - **מוצא רשום :** המוצא כאן קומבינטורי. אם רוצים מוצא נקי ישירות מ-Flip-Flop, אפשר לרשום
      גם את `pulse`, במחיר השהיה של מחזור אחד.
    - **פולס ארוך יותר :** איך מרחיבים את הפולס ל-N מחזורים? מוסיפים מונה שנטען בעליית
      השפה ומחזיק את המוצא גבוה עד שהוא מתאפס.
