## השאלה

מצאו מספר בן 10 ספרות, \( d_0 d_1 \dots d_9 \) משמאל לימין, שבו **הספרה במקום \( i \)
אומרת כמה פעמים הספרה \( i \) מופיעה במספר כולו** : \( d_0 \) הוא מספר האפסים במספר,
\( d_1 \) מספר האחדים, \( d_2 \) מספר השתיים, וכן הלאה עד \( d_9 \), מספר התשיעיות.
מספר כזה **מתאר את עצמו**.

כך זה נראה במספר קטן יותר, בבסיס 4 : המספר 1210 מתאר את עצמו. במקום 0 כתוב 1, ובאמת יש
בו אפס אחד. במקום 1 כתוב 2, ויש בו שני אחדים. במקום 2 כתוב 1, ויש בו שתיים אחת. במקום 3
כתוב 0, ואין בו אף שלוש :

### סעיף א – המספר בבסיס 10

מצאו את המספר. אחר כך כתבו פונקציה שמוצאת את **כל** המספרים שמתארים את עצמם בבסיס
\( b \), עם \( b \) ספרות מ-0 עד \( b - 1 \), בלי לעבור על כל \( b^b \) המחרוזות.

??? tip "רמז 1"
    כמה ספרות יש במספר? כל ספרה נספרת בדיוק באחד המקומות. מה זה אומר על הסכום
    \( d_0 + d_1 + \dots + d_9 \)?

??? tip "רמז 2"
    סכמו את כל הספרות של המספר בשתי דרכים : לפי המקומות, ולפי הערכים. הספרה \( i \)
    מופיעה \( d_i \) פעמים, וכל מופע תורם \( i \).

??? tip "רמז 3"
    שני הסכומים מראים שרוב הספרות הן אפסים. בחיפוש, ממלאים מקום אחרי מקום, וחותכים
    ענף ברגע שאחד הסכומים עובר את \( b \).

??? success "פתרון סעיף א"
    !!! answer "תשובה בקצרה"
        המספר הוא **6210001000** : שישה אפסים, שני אחדים, שתיים אחת ושש אחת. לכל מספר כזה
        יש שני סכומים שווים ל-\( b \) : \( \sum d_i = b \) ו-\( \sum i \cdot d_i = b \).
        חיפוש שממלא ספרה אחרי ספרה וחותך כשאחד הסכומים עובר את \( b \) בודק בבסיס 10 רק
        980 מועמדים מלאים, במקום \( 10^{10} \).

    #### הרעיון { .sol-idea }

    **שני סכומים.** במספר יש \( b \) ספרות, וכל אחת מהן נספרת בדיוק באחד המקומות, במקום
    של הערך שלה. לכן

    \[ d_0 + d_1 + \dots + d_{b-1} = b. \tag{1} \]

    עכשיו סוכמים את הספרות עצמן. לפי המקומות זה \( d_0 + d_1 + \dots \), כלומר שוב
    \( b \). לפי הערכים, הספרה \( i \) מופיעה \( d_i \) פעמים ותורמת \( i \) בכל פעם.
    לכן

    \[ \begin{aligned} &0 \cdot d_0 + 1 \cdot d_1 + 2 \cdot d_2 + \dots \\ &\quad + (b - 1) \cdot d_{b-1} = b. \end{aligned} \tag{2} \]

    **מה זה אומר.** לפי (2), במקום גדול יכולה להיות רק ספרה קטנה : במקום 6 לכל היותר 1,
    ובמקומות 7, 8 ו-9 בבסיס 10 גם 1 כבר לוקח כמעט את כל התקציב. לכן רוב הספרות אפסים,
    ו-\( d_0 \) גדול. אבל ניחוש ותיקון ביד לא מתכנס מעצמו : כל תיקון משנה את הספירה של
    מקום אחר. צריך שיטה.

    **החיפוש.** ממלאים את המקומות לפי הסדר, כל ערך מ-0 ומעלה, ושומרים את שני הסכומים של
    מה שכבר נכתב. כל הספרות והמקומות אי־שליליים, ולכן הסכומים רק גדלים. ברגע שאחד מהם
    עובר את \( b \), אין טעם להמשיך את הענף, וגם לא לנסות ערך גדול יותר באותו מקום.

    #### השלבים { .sol-steps }

    <div class="steps" markdown>

    1. **מקום אחרי מקום :** ממלאים את \( d_0 \), אחר כך את \( d_1 \), וכן הלאה. בכל מקום
       מנסים ערכים מ-0 ומעלה.
    2. **חיתוך :** אם הסכום של הספרות עד עכשיו, או הסכום \( \sum i \cdot d_i \) עד עכשיו,
       עובר את \( b \), חותכים את הערך הזה ואת כל הגדולים ממנו, וחוזרים מקום אחד אחורה.
    3. **בדיקה :** כשכל \( b \) הספרות כתובות, סופרים כמה פעמים מופיעה כל ספרה ומשווים
       ל-\( d_i \).
    4. **הסדר :** הערכים נבחרים מהקטן לגדול, ולכן הפתרונות יוצאים בסדר עולה.

    </div>

    #### הקוד { .sol-code }

    === "Python"
        ```python title="self_describing" linenums="1" hl_lines="14 19"
        def is_self_describing(d):
            """d[i] is how many times the digit i appears in d, for every position i."""
            return all(d.count(i) == d[i] for i in range(len(d)))


        def self_describing(b):
            """Every self-describing number of b digits in base b, as lists of digits, in
            increasing order. The digits are filled from position 0; a value is cut, with every
            larger one, when the digits so far add up to more than b, or sum(i * d[i]) does."""
            found, d = [], []

            def extend(total, weight):
                i = len(d)
                if i == b:                                   # (1)!
                    if is_self_describing(d):
                        found.append(d.copy())
                    return
                for v in range(b):
                    if total + v > b or weight + i * v > b:  # (2)!
                        break
                    d.append(v)
                    extend(total + v, weight + i * v)
                    d.pop()

            extend(0, 0)
            return found
        ```

        1. כל \( b \) הספרות כתובות : רק עכשיו סופרים ומשווים.
        2. הסכום (1) או הסכום (2) עובר את \( b \). ערך גדול יותר באותו מקום רק מגדיל את
           שניהם, ולכן `break` ולא `continue`.

    === "SystemVerilog"
        ```systemverilog title="function automatic int self_describing" linenums="1" hl_lines="12 13 24"
        // Every self-describing number of b digits in base b (2 <= b <= 16), as strings of
        // digits ("6210001000"), in increasing order: the search of the Python, without recursion.
        function automatic int self_describing(int b, output string found[$]);
          string HEX = "0123456789ABCDEF";
          int d[16], total[17], weight[17];
          int i = 0, c;
          bit ok;
          string s;
          found.delete();
          d[0] = -1; total[0] = 0; weight[0] = 0;
          while (i >= 0) begin
            d[i]++;                                                  // (1)!
            if (d[i] >= b || total[i] + d[i] > b || weight[i] + i * d[i] > b) begin
              i--;                                                   // (2)!
              continue;
            end
            total[i + 1] = total[i] + d[i];
            weight[i + 1] = weight[i] + i * d[i];
            if (i < b - 1) begin
              i++;
              d[i] = -1;
              continue;
            end
            ok = 1;                                                  // (3)!
            for (int k = 0; k < b; k++) begin
              c = 0;
              for (int j = 0; j < b; j++) if (d[j] == k) c++;
              if (c != d[k]) ok = 0;
            end
            if (ok) begin
              s = "";
              for (int j = 0; j < b; j++) s = {s, HEX.substr(d[j], d[j])};
              found.push_back(s);
            end
          end
          return found.size();
        endfunction
        ```

        1. הערך הבא במקום \( i \). מחסנית הקריאות של Python היא כאן המערכים : `total[i]`
           ו-`weight[i]` הם שני הסכומים של המקומות שלפני \( i \).
        2. חיתוך : הערך הזה וכל הגדולים ממנו לא יכולים להשתלים, אז חוזרים מקום אחד אחורה.
           כש-\( i \) יורד מתחת ל-0, החיפוש נגמר.
        3. כל \( b \) הספרות כתובות : סופרים כל ספרה ומשווים, כמו `is_self_describing`.

    #### למה זה נכון { .sol-proof }

    **שום פתרון לא נחתך.** בכל פתרון שני הסכומים שווים בדיוק ל-\( b \), ולכן בכל קידומת
    שלו הם לכל היותר \( b \). חיתוך קורה רק לקידומת שאחד הסכומים שלה כבר עבר את \( b \),
    ולכן הוא אף פעם לא חותך קידומת של פתרון. **ושום דבר אחר לא עובר** : כל מועמד מלא
    נבדק מול ההגדרה עצמה.

    **צעד אחרי צעד.** כאן החיפוש בבסיס 4, אירוע אחרי אירוע : כל צעד הוא חיתוך, או מועמד

### סעיף ב – למה אין עוד אחד בבסיס 10

החיפוש מצא רק את 6210001000. הוכיחו, בלי מחשב, שאין מספר אחר בן 10 ספרות שמתאר את
עצמו.

??? tip "רמז 1"
    נסמן \( z = d_0 \), מספר האפסים. חסרו את (1) מ-(2). מה נשאר?

??? tip "רמז 2"
    יוצא \( \sum_{i \ge 2} (i - 1) \cdot d_i = z \). הספרה \( z \) עצמה כתובה במקום 0,
    ולכן \( d_z \ge 1 \). כמה מהסכום היא כבר "תופסת" כש-\( z \ge 3 \)?

??? success "פתרון סעיף ב"
    !!! answer "תשובה בקצרה"
        מ-(2) פחות (1) : \( \sum_{i \ge 2} (i - 1) d_i = z \), כש-\( z = d_0 \ge 1 \).
        אם \( z \ge 3 \), הספרה \( z \) תופסת \( z - 1 \) מהסכום, ונשארת יחידה אחת : ספרה
        2 אחת בדיוק. ואז \( d_1 = 2 \), ו-\( z + 4 = 10 \) נותן \( z = 6 \). אם \( z = 1 \)
        או \( z = 2 \), מספר האחדים יוצא 8 או 6, ספרה שאסור לה להופיע. לכן 6210001000
        הוא היחיד.

    #### הרעיון { .sol-idea }

    **משוואה אחת.** מחסרים את (1) מ-(2), איבר באיבר :

    \[ \begin{aligned} \sum_{i=0}^{9} (i - 1) \cdot d_i &= 0 \\ \Longrightarrow\quad \sum_{i \ge 2} (i - 1) \cdot d_i &= d_0 = z. \end{aligned} \tag{*} \]

    האיבר של \( i = 1 \) מתאפס, והאיבר של \( i = 0 \) הוא \( -z \). המשמעות : כל ספרה
    \( i \ge 2 \) "עולה" \( i - 1 \), והתקציב הכולל הוא מספר האפסים. ספרות 0 ו-1 לא עולות
    כלום.

    **שתי עובדות קטנות.** קודם, \( z \ge 1 \) : אם \( d_0 = 0 \), הספרה 0 כתובה במקום 0,
    ואז יש במספר אפס, בסתירה. שנית, הספרה \( z \) כתובה במקום 0, ולכן \( d_z \ge 1 \).

    #### השלבים { .sol-steps }

    <div class="steps" markdown>

    1. **‏\( z \ge 3 \) :** האיבר של \( i = z \) ב-(*) הוא \( (z - 1) d_z \ge z - 1 \).
       הוא לא יכול להיות \( 2(z - 1) \), כי זה יותר מ-\( z \). לכן \( d_z = 1 \), ומהתקציב
       נשארת יחידה אחת. רק ספרה 2 עולה בדיוק 1, ולכן יש שתיים אחת, ואין עוד ספרה גדולה
       מ-2 מלבד \( z \).
    2. **מי הם השאר :** הספרות שאינן אפס הן \( d_0 = z \), \( d_2 = 1 \) (שתיים אחת),
       \( d_z = 1 \) ו-\( d_1 \). השתיים חייבת להיות באחד המקומות האלה, ואפשר רק את
       \( d_1 \). לכן \( d_1 = 2 \), ובאמת יש בדיוק שני אחדים, \( d_2 \) ו-\( d_z \).
    3. **הספירה :** ‏\( z \) אפסים ועוד הספרות \( z, 2, 1, 1 \) הן כל עשר הספרות :
       \( z + 4 = 10 \), כלומר \( z = 6 \). המספר : 6210001000.
    4. **‏\( z = 1 \) :** לפי (*) יש שתיים אחת ואין ספרה גדולה מ-2. אז יש אפס אחד, שתיים
       אחת, ושמונה אחדים, כלומר \( d_1 = 8 \) : ספרה 8, שאסור לה להופיע.
    5. **‏\( z = 2 \) :** ‏\( d_2 \ge 1 \), ו-(*) אומר \( d_2 + 2 d_3 + \dots = 2 \). אם
       \( d_2 = 1 \), שאר הסכום הוא 1, אבל כל ספרה \( i \ge 3 \) עולה לפחות 2. לכן \( d_2 = 2 \)
       ואין ספרה גדולה מ-2 : שני אפסים, שתי שתיים ושישה אחדים, כלומר \( d_1 = 6 \). שוב
       ספרה אסורה.

    </div>

    #### למה זה נכון { .sol-proof }

    שלושת המקרים מכסים כל \( z \ge 1 \), ורק המקרה \( z \ge 3 \) נותן מספר, ורק אחד :

    <!-- gen 3 -->

    | ‏\( z = d_0 \) | מה (*) מכריח | כמה אחדים | אפשר? |
    |:-:|---|---|:-:|
    | ‏\( z = 1 \) | שתיים אחת, ואין ספרה גדולה מ-2 | ‏\( d_1 = 8 \) : ספרה גדולה מ-2, שאסור שתופיע | לא |
    | ‏\( z = 2 \) | שתי ספרות 2, ואין ספרה גדולה מ-2 | ‏\( d_1 = 6 \) : ספרה גדולה מ-2, שאסור שתופיע | לא |
    | ‏\( z \ge 3 \) | הספרה ‏\( z \) מופיעה פעם אחת, יש שתיים אחת, ואין עוד ספרה גדולה מ-2 | ‏\( d_1 = 2 \), ואז \( z = 10 - 4 = 6 \) | כן |

    <!-- /gen -->

    כל צעד נשען רק על (1), (2) ועל ההגדרה, ולכן ההוכחה לא תלויה בחיפוש. החיפוש של סעיף א
    מאשר את אותה תוצאה מהכיוון השני.

### סעיף ג – כל בסיס

בבסיס \( b \) יש למספר \( b \) ספרות, מ-0 עד \( b - 1 \), וההגדרה אותה הגדרה. באילו
בסיסים יש מספרים שמתארים את עצמם, ומה הם? הוכיחו שהרשימה מלאה, וכתבו קוד שבודק אותה
מול החיפוש עד בסיס 16.

??? tip "רמז 1"
    המשוואה (*) לא תלויה ב-10 : \( \sum_{i \ge 2} (i - 1) d_i = z \) בכל בסיס. עברו על
    אותם שלושה מקרים, עם \( b \) במקום 10.

??? tip "רמז 2"
    במקרה \( z \ge 3 \) יוצא \( z = b - 4 \). מתי זה בכלל \( \ge 3 \)? ובמקרים
    \( z = 1, 2 \), מספר האחדים הוא \( b - 2 \) או \( b - 4 \). מתי הוא ספרה שמותרת?

??? success "פתרון סעיף ג"
    !!! answer "תשובה בקצרה"
        לכל \( b \ge 7 \) יש מספר אחד בדיוק : הספרה \( b - 4 \), אחריה 2 ו-1, אפסים, 1
        במקום \( b - 4 \), ושלושה אפסים בסוף. למשל 3211000 בבסיס 7 ו-6210001000 בבסיס 10.
        בבסיס 4 יש שניים, 1210 ו-2020, ובבסיס 5 אחד, 21200. בבסיסים 2, 3 ו-6 אין אף אחד.

    <!-- cost: זמן \( O(b) \) לנוסחה | בדיקה עד בסיס 16 -->

    #### הרעיון { .sol-idea }

    אותה משוואה (*), ואותם שלושה מקרים. ההבדל היחיד : במקום "עשר הספרות" יש \( b \)
    ספרות, ולכן הספירה בסוף כל מקרה נותנת משוואה ב-\( b \).

    #### השלבים { .sol-steps }

    === "Python"
        ```python title="predicted" linenums="1" hl_lines="6"
        def predicted(b):
            """The list of part c: for b >= 7 one number, (b - 4) 2 1 0 ... 0 1 0 0 0; two in
            base 4, one in base 5, none in bases 2, 3 and 6."""
            if b >= 7:
                d = [0] * b
                d[0], d[1], d[2], d[b - 4] = b - 4, 2, 1, 1     # (1)!
                return [d]
            return {4: [[1, 2, 1, 0], [2, 0, 2, 0]], 5: [[2, 1, 2, 0, 0]]}.get(b, [])


        def differ(top=16):
            """The bases up to top where the search of part a and the list disagree: none."""
            return [b for b in range(2, top + 1) if self_describing(b) != predicted(b)]
        ```

## נקודות חשובות ושאלות המשך

??? trap "מלכודת : לשכוח שהספרה סופרת גם את עצמה"
    הספרה \( d_i \) היא חלק מהמספר. ‏9000000000 נראה כמו "תשעה אפסים", אבל ה-9 עצמו הוא
    תשיעייה, ולכן \( d_9 \) צריך להיות 1, ואז יש רק שמונה אפסים, וכן הלאה. כל ניחוש צריך
    לספור את כל עשר הספרות, כולל המקום שהשתנה.

??? trap "מלכודת : לעבור על כל המחרוזות"
    ‏\( 10^{10} \) מחרוזות הן עשרה מיליארד בדיקות. שני הסכומים חותכים את זה ל-980 מועמדים
    מלאים. עם הסכום (1) בלבד, החיפוש בודק ‏184,746 מועמדים, בערך פי 190.

??? trap "מלכודת : החיפוש כהוכחה"
    "הקוד מצא מספר אחד" מוכיח משהו רק אם הקוד לא חותך פתרונות בטעות. החיתוך כאן בטוח כי
    שני הסכומים שווים בדיוק ל-\( b \) בכל פתרון. בראיון כדאי להגיד את זה במפורש, ולתת
    גם את ההוכחה של סעיף ב.

??? followup "שאלות המשך"
    - **פחות ספרות מהבסיס :** מספר בן \( n \) ספרות בבסיס 10, \( n < 10 \), שבו
      \( d_i \) הוא מספר המופעים של \( i \), לכל \( i < n \). מה הם?

        ??? fu-answer "תשובה"
            בדיוק המספרים של בסיס \( n \) : ‏1210, 2020, 21200, 3211000 וכן הלאה. ספרה
            \( v \ge n \) במקום \( j \) אומרת ש-\( j \) מופיע \( v \ge n \) פעמים, כלומר
            כל הספרות הן \( j \), ואז \( v = j < n \), בסתירה.

    - **כמה זמן לוקח בסיס 16?** כמה מועמדים מלאים בודק החיפוש, ומה המספר?

        ??? fu-answer "תשובה"
            ‏10,459 מועמדים מלאים, והמספר הוא C210000000001000 : \( b - 4 = 12 \) הוא C
            בבסיס 16, וה-1 של המקום 12 הוא בספרה ה-13.

    - **משפט שמתאר את עצמו :** "במשפט הזה יש שלוש אותיות א..." איך מחפשים משפט כזה?

        ??? fu-answer "תשובה"
            אותו רעיון של נקודת שבת : המונים במשפט צריכים להיות שווים לספירה של המשפט.
            מתחילים מניחוש, סופרים, מעדכנים את המונים וחוזרים, ועוצרים כשהספירה לא
            משתנה. זה לא תמיד מתכנס, ולכן מוסיפים אקראיות או חיפוש עם גיזום כמו כאן.
