## השאלה

יש לך \( N \) כדורים, ממוספרים \( 1 \) עד \( N \). כולם שוקלים אותו דבר, חוץ מכדור אחד
שהוא **קל יותר או כבד יותר** מהשאר. אתה לא יודע איזה כדור, ולא יודע אם הוא קל או כבד.

יש לך מאזני כפות, שזמינים דרך הפונקציה `weigh`. המאזניים משווים את **סך המשקל** בכל
כף, ולכן אם שמים מספר שונה של כדורים בכל צד, התוצאה לא תגיד הרבה. אסור לשים אותו כדור
בשתי הכפות באותה שקילה. עליך לממש פונקציה שמחזירה את מספר הכדור החריג ואת סוגו :

=== "SystemVerilog"
    ```systemverilog title="scale, odd_t"
    // The balance: weigh() puts the balls of `left` on the left pan and those of `right` on
    // the right pan, and returns +1 when the left pan is heavier, -1 when the right pan is,
    // and 0 when they balance. A ball may not be on both pans.
    virtual class scale;
      pure virtual function int weigh(int left[$], int right[$]);
    endclass

    typedef struct { int ball; bit heavy; } odd_t;     // the odd ball, and whether it is heavy
    ```

      הוא לבחור קודים שבכל שקילה שמים אותו מספר כדורים בשתי הכפות.
    - **רמה :** סעיפים א ו-ב מתאימים לראיון רגיל. סעיף ג מתאים כשאלת המשך למועמדים

### סעיף א – 12 כדורים בשלוש שקילות

‏\( N = 12 \), ומותר לקרוא ל-`weigh` לכל היותר **3 פעמים**. הסבר איך פותרים, ומה
עושים בכל תוצאה אפשרית.

??? tip "רמז 1"
    כמה אפשרויות יש (איזה כדור, וקל או כבד), וכמה תוצאות שונות יכולות לצאת משלוש
    שקילות? מה זה אומר על כמה אפשרויות מותר להשאיר אחרי כל שקילה?

??? tip "רמז 2"
    אחרי שקילה ראשונה לא מאוזנת יש 8 אפשרויות. איך מחלקים אותן ל-3, ‏3 ו-2? נסו לערבב
    בין מועמדים לכבד ולקל, ולהעביר כדור אחד לכף השנייה.

??? success "פתרון סעיף א"
    !!! answer "תשובה בקצרה"
        **עץ החלטות :** 1 עד 4 מול 5 עד 8. אם מאוזן, החריג בין 9 ל-12, והשקילה השנייה
        מול כדורים תקינים. אם לא מאוזן, השקילה השנייה מערבבת מועמדים לכבד ולקל ומעבירה
        כדור לכף השנייה, כך ש-8 האפשרויות מתפצלות ל-3, ‏3 ו-2. שלוש שקילות מספיקות לכל
        24 המקרים.

    <!-- cost: שקילות 3 | אפשרויות 24 מתוך 27 תוצאות -->

    #### הרעיון { .sol-idea }

    **ספירה.** יש \( 12 \times 2 = 24 \) אפשרויות : כל כדור יכול להיות קל או כבד. לכל
    שקילה 3 תוצאות, ולכן לשלוש שקילות יש \( 3^3 = 27 \) תוצאות. מאחר ש-\( 27 \ge 24 \),
    ייתכן שאפשר. הטריק הוא לחלק את האפשרויות בכל שקילה לשלוש קבוצות כמעט שוות : אחרי
    השקילה הראשונה נשארות לכל היותר 9 אפשרויות, ואחרי השנייה לכל היותר 3, ששקילה אחת
    מפרידה.

    #### השלבים { .sol-steps }

    <div class="steps" markdown>

    1. **שקילה ראשונה, 1 עד 4 מול 5 עד 8 :** מכל תוצאה נשארות 8 אפשרויות.
        - **מאוזן :** אחד מ-9 עד 12 חריג, קל או כבד. הכדורים 1 עד 8 תקינים.
        - **שמאל כבד :** או שאחד מ-1 עד 4 כבד, או שאחד מ-5 עד 8 קל. הכדורים 9 עד 12
          תקינים.
        - **ימין כבד :** סימטרי.
    2. **אם השקילה הראשונה מאוזנת :** השקילה השנייה היא 9, ‏10, ‏11 מול 1, ‏2, ‏3, כדורים
       תקינים.

        | תוצאה | מה ידוע | שקילה 3 | פענוח |
        |---|---|---|---|
        | מאוזן | ‏12 חריג | ‏12 מול 1 | שמאל כבד : 12 כבד. ימין כבד : 12 קל |
        | שמאל כבד | אחד מ-9, ‏10, ‏11 כבד | ‏9 מול 10 | הכבד מביניהם הוא החריג. מאוזן : 11 כבד |
        | ימין כבד | אחד מ-9, ‏10, ‏11 קל | ‏9 מול 10 | הקל מביניהם הוא החריג. מאוזן : 11 קל |

    3. **אם השקילה הראשונה לא מאוזנת :** נסמן ב-\( h_1, h_2, h_3, h_4 \) את הכדורים בכף
       שירדה (מועמדים להיות כבדים), וב-\( l_1, l_2, l_3, l_4 \) את הכדורים בכף שעלתה
       (מועמדים להיות קלים). כדור 9 תקין. השקילה השנייה היא \( h_1, h_2, l_1 \) מול
       \( h_3, l_2, 9 \) :

        | תוצאה | מועמדים | שקילה 3 | פענוח |
        |---|---|---|---|
        | שמאל כבד | ‏\( h_1 \) או \( h_2 \) כבד, או \( l_2 \) קל | ‏\( h_1 \) מול \( h_2 \) | הכבד מביניהם הוא החריג. מאוזן : \( l_2 \) קל |
        | ימין כבד | ‏\( h_3 \) כבד, או \( l_1 \) קל | ‏\( h_3 \) מול 9 | שמאל כבד : \( h_3 \) כבד. מאוזן : \( l_1 \) קל |
        | מאוזן | ‏\( h_4 \) כבד, או \( l_3 \) או \( l_4 \) קל | ‏\( l_3 \) מול \( l_4 \) | הקל מביניהם הוא החריג. מאוזן : \( h_4 \) כבד |

    </div>

    #### הקוד { .sol-code }

    === "SystemVerilog"
        ```systemverilog title="odd_ball_12_tree" linenums="1"
        // Part a: the decision tree, three weighings at most.
        function automatic odd_t odd_ball_12_tree(scale s);
          int r1, r2, r3, h[4], l[4];
          r1 = s.weigh('{1, 2, 3, 4}, '{5, 6, 7, 8});
          if (r1 == 0) begin                                  // 9 to 12 hold the odd ball, 1 to 8 are genuine
            r2 = s.weigh('{9, 10, 11}, '{1, 2, 3});
            if (r2 == 0) return '{12, s.weigh('{12}, '{1}) == 1};
            r3 = s.weigh('{9}, '{10});
            if (r3 == 0) return '{11, r2 == 1};
            return '{(r3 == r2) ? 9 : 10, r2 == 1};           // the heavier of 9 and 10 when heavy, the lighter when light
          end
          if (r1 == 1) begin h = '{1, 2, 3, 4}; l = '{5, 6, 7, 8}; end   // h: the pan that went down
          else begin h = '{5, 6, 7, 8}; l = '{1, 2, 3, 4}; end
          r2 = s.weigh('{h[0], h[1], l[0]}, '{h[2], l[1], 9});              // (1)!
          if (r2 == 1) begin
            r3 = s.weigh('{h[0]}, '{h[1]});
            if (r3 == 0) return '{l[1], 0};
            return '{(r3 == 1) ? h[0] : h[1], 1};
          end
          if (r2 == -1) begin
            if (s.weigh('{h[2]}, '{9}) == 1) return '{h[2], 1};
            return '{l[0], 0};
          end
          r3 = s.weigh('{l[2]}, '{l[3]});
          if (r3 == 0) return '{h[3], 1};
          return '{(r3 == 1) ? l[3] : l[2], 0};
        endfunction
        ```

        1. ‏\( h_1, h_2 \) נשארים בשמאל, \( h_3 \) עובר לימין, \( l_1 \) עובר לשמאל, \( l_2 \) נשאר בימין, ו-9 התקין משלים את הכף הימנית לשלושה כדורים. \( h_4, l_3, l_4 \) יוצאים.

    === "Python"
        ```python title="find_odd_ball_12_tree" linenums="1"
        def find_odd_ball_12_tree(weigh):
            r1 = weigh([1, 2, 3, 4], [5, 6, 7, 8])
            if r1 == "equal":
                r2 = weigh([9, 10, 11], [1, 2, 3])
                if r2 == "equal":
                    return 12, ("heavy" if weigh([12], [1]) == "left" else "light")
                kind = "heavy" if r2 == "left" else "light"
                r3 = weigh([9], [10])
                if r3 == "equal":
                    return 11, kind
                heavier, lighter = (9, 10) if r3 == "left" else (10, 9)
                return (heavier if kind == "heavy" else lighter), kind

            h, l = ([1, 2, 3, 4], [5, 6, 7, 8]) if r1 == "left" else ([5, 6, 7, 8], [1, 2, 3, 4])
            r2 = weigh([h[0], h[1], l[0]], [h[2], l[1], 9])  # (1)!
            if r2 == "left":
                r3 = weigh([h[0]], [h[1]])
                if r3 == "equal":
                    return l[1], "light"
                return (h[0] if r3 == "left" else h[1]), "heavy"
            if r2 == "right":
                return (h[2], "heavy") if weigh([h[2]], [9]) == "left" else (l[0], "light")
            r3 = weigh([l[2]], [l[3]])
            if r3 == "equal":
                return h[3], "heavy"
            return (l[3] if r3 == "left" else l[2]), "light"
        ```

        1. ‏\( h_1, h_2 \) נשארים בשמאל, \( h_3 \) עובר לימין, \( l_1 \) עובר לשמאל, \( l_2 \) נשאר בימין, ו-9 התקין משלים את הכף הימנית לשלושה כדורים. \( h_4, l_3, l_4 \) יוצאים.

    #### למה זה נכון { .sol-proof }

    **כל ענף נגמר בכדור אחד.** אחרי השקילה הראשונה נשארות 8 אפשרויות בכל ענף. בענף
    המאוזן השקילה השנייה מפצלת אותן ל-2, ‏3 ו-3 : אם היא מאוזנת נשאר רק 12 (קל או
    כבד), ואם לא, הכיוון קובע אם החריג כבד או קל, ונשארים שלושה מועמדים מאותו סוג.
    בענף הלא מאוזן כל כדור במועמדים "הולך" לתוצאה אחרת של השקילה השנייה :

    - **הכבדים \( h_1, h_2 \) והקל \( l_2 \) :** כל אחד מהם מוריד את הכף השמאלית, או
      מרים את הימנית. התוצאה "שמאל כבד".
    - **הכבד \( h_3 \) והקל \( l_1 \) :** מורידים את הכף הימנית. התוצאה "ימין כבד".
    - **הכבד \( h_4 \) והקלים \( l_3, l_4 \) :** לא על המאזניים. התוצאה "מאוזן".

    בכל תוצאה נשארים לכל היותר שלושה מועמדים, והשקילה השלישית מפרידה ביניהם : שניים
    על הכפות והשלישי בחוץ, או מועמד אחד מול כדור תקין. הקוד נבדק על כל 24 המקרים, ובכל
    אחד הוא מחזיר את הכדור ואת הסוג אחרי שלוש שקילות לכל היותר.

    #### סיבוכיות { .sol-cost }

    שלוש קריאות ל-`weigh` לכל היותר, וכל ענף הוא מספר קבוע של השוואות. זה גם המינימום :
    בשתי שקילות יש רק 9 תוצאות, פחות מ-24 אפשרויות.

### סעיף ב – שלוש שקילות שנקבעות מראש

כתוב קוד קצר ככל האפשר ל-\( N = 12 \) בשלוש שקילות. כדאי לחשוב : האם אפשר לקבוע את
שלוש השקילות **מראש**, בלי תלות בתוצאות, ואז רק "לפענח" את התוצאות?

??? tip "רמז 1"
    מה כל כדור "רואה" בשלוש השקילות? בכל שקילה הוא בכף השמאלית, בכף הימנית או בחוץ.

??? tip "רמז 2"
    אם הכדור החריג כבד ונמצא בשמאל, השקילה יורדת שמאלה. איזה וקטור של שלוש תוצאות נותן
    כדור כבד, ואיזה כדור קל באותם מקומות? מתי שני כדורים שונים נותנים אותו וקטור?

??? success "פתרון סעיף ב"
    !!! answer "תשובה בקצרה"
        כל כדור מקבל **קוד** : \( +1 \) בשמאל, \( -1 \) בימין, \( 0 \) בחוץ, בכל אחת
        משלוש השקילות. כדור כבד נותן וקטור תוצאות ששווה לקוד שלו, וכדור קל את ההיפוך.
        בוחרים 12 קודים בלי \( (0, 0, 0) \), בלי קוד יחד עם ההיפוך שלו, ועם 4 כדורים בכל
        כף בכל שקילה, והתשובה נמצאת בטבלת חיפוש.

    <!-- cost: שקילות 3 | פענוח \( O(N) \) -->

    #### הרעיון { .sol-idea }

    **חתימה לכל כדור.** במקום עץ, קובעים מראש איפה כל כדור יהיה בכל אחת משלוש השקילות :
    בשמאל (\( +1 \)), בימין (\( -1 \)) או בחוץ (\( 0 \)). זה נותן לכל כדור **קוד** של
    שלושה סימנים. כשבכל כף אותו מספר כדורים, רק החריג מטה את המאזניים :

    - **אם כדור עם קוד \( c \) כבד :** וקטור התוצאות הוא בדיוק \( c \).
    - **אם הוא קל :** וקטור התוצאות הוא \( -c \).

    #### השלבים { .sol-steps }

    <div class="steps" markdown>

    1. **שלושה כללים לבחירת הקודים :**
        - **אסור הקוד \( (0, 0, 0) \) :** כדור שלא נשקל אף פעם לא מגלה אם הוא קל או כבד.
        - **אסור להשתמש גם ב-\( c \) וגם ב-\( -c \) :** אחרת "הראשון כבד" ו"השני קל" נראים
          זהים.
        - **בכל שקילה, 4 כדורים בכל צד :** אחרת המאזניים נוטים בגלל מספר הכדורים.
    2. **כמה קודים יש :** ‏\( 27 - 1 = 26 \) קודים, שהם 13 זוגות של קוד והיפוכו. בוחרים 12
       זוגות, ומכל זוג נציג אחד, כך שכל עמודה מאוזנת. הזוג שנשאר בחוץ כאן הוא
       \( \pm(1, -1, 1) \).
    3. **הקודים :** כל עמודה היא שקילה. למשל, שקילה 2 היא 1, ‏4, ‏8, ‏9 מול 3, ‏6, ‏10, ‏11.

        | כדור | שקילה 1 | שקילה 2 | שקילה 3 |
        |:-:|:-:|:-:|:-:|
        | ‏1 | ‏\( +1 \) | ‏\( +1 \) | ‏\( 0 \) |
        | ‏2 | ‏\( +1 \) | ‏\( 0 \) | ‏\( +1 \) |
        | ‏3 | ‏\( +1 \) | ‏\( -1 \) | ‏\( 0 \) |
        | ‏4 | ‏\( +1 \) | ‏\( +1 \) | ‏\( -1 \) |
        | ‏5 | ‏\( -1 \) | ‏\( 0 \) | ‏\( 0 \) |
        | ‏6 | ‏\( -1 \) | ‏\( -1 \) | ‏\( -1 \) |
        | ‏7 | ‏\( -1 \) | ‏\( 0 \) | ‏\( +1 \) |
        | ‏8 | ‏\( -1 \) | ‏\( +1 \) | ‏\( +1 \) |
        | ‏9 | ‏\( 0 \) | ‏\( +1 \) | ‏\( 0 \) |
        | ‏10 | ‏\( 0 \) | ‏\( -1 \) | ‏\( +1 \) |
        | ‏11 | ‏\( 0 \) | ‏\( -1 \) | ‏\( -1 \) |
        | ‏12 | ‏\( 0 \) | ‏\( 0 \) | ‏\( -1 \) |

    4. **השקילות :** שקילה 1 היא 1 עד 4 מול 5 עד 8; שקילה 2 היא 1, ‏4, ‏8, ‏9 מול 3, ‏6,
       ‏10, ‏11; שקילה 3 היא 2, ‏7, ‏8, ‏10 מול 4, ‏6, ‏11, ‏12.
    5. **הפענוח :** מחפשים בטבלה את הקוד ששווה לוקטור התוצאות (הכדור כבד), או את הקוד
       ששווה להיפוך שלו (הכדור קל).

    </div>

    **נסו בעצמכם.** התיבה מציירת את שלוש השקילות כשורות של מאזניים, ומתחת להן את טבלת
    ההחלטות, שורה לכל אחד מ-27 הווקטורים. בוחרים כדור חריג וקל או כבד, או לוחצים על
    שורה : הכדור נצבע (כבד באדום, קל בכחול), הכפות נוטות לפי התוצאה שהוא גורם, והשורה

### סעיף ג – הכלל לכל N { #any-n }

מהו מספר השקילות המינימלי ל-\( N \) כדורים, ואיך משיגים אותו?

??? tip "רמז 1"
    קודם החסם. יש \( 2N \) אפשרויות ו-\( 3^k \) תוצאות, אבל אחת התוצאות לא יכולה
    לזהות כדור **וגם** את הסוג שלו. איזו?

??? tip "רמז 2"
    אחרי שקילה ראשונה מאוזנת יש כדורים שידוע שהם תקינים. כמה כדורים אפשר לפתור
    ב-\( m \) שקילות כשיש כדור תקין לעזרה? ואם השקילה הראשונה לא מאוזנת, כמה אפשרויות
    נשארות?

??? tip "רמז 3"
    הבנייה : אותם קודים כמו בסעיף ב. השאלה היחידה היא איך לבחור קודים שבכל שקילה
    מאוזנים. נסו לקחת קודים בשלשות, \( c \), ‏\( c + 1 \), ‏\( c + 2 \) מודולו 3 בכל ספרה.

??? success "פתרון סעיף ג"
    !!! answer "תשובה בקצרה"
        ‏\( k = \lceil \log_3(2N + 3) \rceil \) שקילות. כלומר ב-\( k \) שקילות אפשר לטפל
        בעד \( \frac{3^k - 3}{2} \) כדורים : 3 בשתי שקילות, 12 בשלוש, 39 בארבע, 120 בחמש
        ו-363 בשש. הבנייה : קודים "נכונים" של דייסון בשלשות מאוזנות, וכדורים תקינים
        שמשלימים את הכפות מהשקילה השנייה.

    <!-- cost: שקילות \( \lceil \log_3(2N + 3) \rceil \) | זמן \( O(N \log N) \) -->

    #### הרעיון { .sol-idea }

    אותה שיטה כמו בסעיף ב : כל כדור מקבל קוד באורך \( k \) מתוך \( \{+1, -1, 0\} \),
    הקודים שונים, אין קוד יחד עם ההיפוך שלו, והפענוח הוא השוואה לקוד או להיפוך שלו.
    השאלה היחידה היא **איך לבחור קודים מאוזנים** בצורה שיטתית, ומה עושים כש-\( N \) לא
    מתחלק ב-3.

    | שקילות \( k \) | מקסימום כדורים |
    |:-:|:-:|
    | ‏2 | ‏3 |
    | ‏3 | ‏12 |
    | ‏4 | ‏39 |
    | ‏5 | ‏120 |
    | ‏6 | ‏363 |

    #### השלבים { .sol-steps }

    <div class="steps" markdown>

    1. **החסם התחתון :** יש \( 2N \) אפשרויות ו-\( 3^k \) תוצאות. התוצאה "מאוזן בכל
       השקילות" לא יכולה לזהות כדור **וגם** את הסוג שלו, ולכן \( 2N \le 3^k - 1 \). אבל
       אפשר להדק. נניח שבשקילה הראשונה יש \( a \) כדורים בכל כף :
        - **אם המאזניים נוטים :** נשארות \( 2a \) אפשרויות ל-\( k - 1 \) שקילות. ‏\( 2a \)
          זוגי ו-\( 3^{k-1} \) אי-זוגי, ולכן \( 2a \le 3^{k-1} - 1 \).
        - **אם מאוזן :** נשארים \( N - 2a \) כדורים, אבל עכשיו יש כדורים תקינים לעזרה. עם
          עזר כזה, \( k - 1 \) שקילות מטפלות בעד \( \frac{3^{k-1} - 1}{2} \) כדורים.

        ביחד :

        \[
        \begin{aligned}
        N &\le (3^{k-1} - 1) + \frac{3^{k-1} - 1}{2} = \frac{3^k - 3}{2} \\
        &\Longleftrightarrow\quad k \ge \lceil \log_3(2N + 3) \rceil
        \end{aligned}
        \]

    2. **קודים "נכונים" :** נכתוב את הקודים בספרות \( \{0, 1, 2\} \) : ‏0 לימין, 1 לבחוץ
       ו-2 לשמאל, כלומר \( d \mapsto d - 1 \). ההיפוך של קוד הוא \( d \mapsto 2 - d \).
       קוד נקרא **נכון** אם בשינוי הראשון בין ספרות סמוכות הספרה עולה ב-1 מודולו 3
       (‏\( 0 \to 1 \), ‏\( 1 \to 2 \), ‏\( 2 \to 0 \)). מכל זוג של קוד והיפוכו בדיוק אחד
       נכון, כי ההיפוך הופך עלייה לירידה. הקודים הקבועים (כל הספרות שוות) אינם נכונים.
    3. **מסלולים מאוזנים :** אם מוסיפים 1 מודולו 3 לכל הספרות, ההפרשים לא משתנים, ולכן
       כל קוד נכון שייך ל**מסלול** של שלושה קודים נכונים \( c \), ‏\( c + 1 \), ‏\( c + 2 \).
       בכל עמודה שלושת חברי המסלול מכסים בדיוק את \( \{+1, -1, 0\} \), ולכן מסלול שלם
       מוסיף כדור אחד לכל כף בכל שקילה. יש \( \frac{3^k - 3}{6} \) מסלולים, כלומר עד
       \( \frac{3^k - 3}{2} \) כדורים מאוזנים לגמרי.
    4. **כש-\( N \) לא מתחלק ב-3 :** לוקחים \( q = \lceil N / 3 \rceil \) מסלולים, ובמסלול
       האחרון רק חלק :
        - **‏\( N = 3q - 1 \) :** משמיטים את החבר שבשקילה 1 בחוץ (‏\( 0 \) בשקילה 1).
        - **‏\( N = 3q - 2 \) :** משמיטים את שני החברים שבשקילה 1 בשמאל ובימין
          (‏\( +1 \) ו-\( -1 \)). הם מבטלים זה את זה בשקילה 1.

        בשני המקרים **השקילה הראשונה מאוזנת**. בשקילות הבאות ייתכן הפרש של כדור אחד בין
        הכפות.
    5. **איזון בעזרת כדור תקין :** אחרי השקילה הראשונה יודעים שחלק מהכדורים תקינים : אם
       היא מאוזנת, כל מי שהיה על המאזניים; אם נטתה, כל מי שהיה בחוץ. בכל שקילה מהשנייה
       והלאה, אם בכפות מספר שונה של כדורים, **מוציאים כדור תקין מהכף העמוסה, או מוסיפים
       כדור תקין מבחוץ לכף החסרה**. כדור תקין לא משנה את התוצאה, ולכן הפענוח לא משתנה.

    </div>

    בונה את המסלולים, ומסמנת בקו מקווקו כל כדור תקין שהוכנס לכף או הוצא ממנה כדי לאזן
    (למשל עם 13 כדורים) :

    === "SystemVerilog"
        ```systemverilog title="correct, odd_ball" linenums="1"
        localparam int MAXK = 6, MAXN = 363;      // six weighings handle up to 363 balls

        // A code in the digits 0, 1, 2 is correct when its first change between neighbours goes
        // up by 1 (mod 3).
        function automatic bit correct(int c[MAXK], int k);
          for (int i = 0; i + 1 < k; i++)
            if (c[i] != c[i + 1]) return (c[i + 1] - c[i] + 3) % 3 == 1;
          return 0;
        endfunction

        // Part c: the fewest weighings for any n from 3 to MAXN.
        function automatic odd_t odd_ball(int n, scale s);
          int k = 2, q, extra, nb = 0, p, m, c[MAXK], code[MAXN][MAXK], out[MAXK], L[$], R[$];
          bit match, flip;
          while ((3 ** k - 3) / 2 < n) k++;
          q = (n + 2) / 3; extra = (3 - n % 3) % 3;
          p = 3 ** (k - 1);
          // one representative per orbit: a correct code whose first digit is 1 (off the scale),
          // in lexicographic order; its orbit gets the first digits +1, -1, 0
          for (int v = 0; v < p && nb < 3 * q; v++) begin
            c[0] = 1; m = v;
            for (int j = k - 1; j >= 1; j--) begin c[j] = m % 3; m /= 3; end
            if (!correct(c, k)) continue;
            foreach (code[0][j]) if (j < k) begin
              code[nb][j] = (c[j] + 1) % 3 - 1; code[nb + 1][j] = (c[j] + 2) % 3 - 1; code[nb + 2][j] = c[j] - 1;
            end
            nb += 3;
          end
          if (extra == 1) nb--;                    // drop the member off the scale in weighing 1
          else if (extra == 2) begin               // drop the +1 / -1 pair, they cancel in weighing 1
            code[nb - 3] = code[nb - 1];
            nb -= 2;
          end
          for (int j = 0; j < k; j++) begin
            L.delete(); R.delete();
            for (int b = 0; b < nb; b++)
              if (code[b][j] == 1) L.push_back(b + 1);
              else if (code[b][j] == -1) R.push_back(b + 1);
            // from weighing 2 on, even the pans with balls known to be genuine after weighing 1
            for (int b = 0; j > 0 && b < nb && L.size() != R.size(); b++) begin
              if (code[b][0] == out[0] || code[b][0] == -out[0]) continue;     // not known genuine
              if (L.size() > R.size()) begin
                if (code[b][j] == 1) L.delete(find(L, b + 1)); else if (code[b][j] == 0) R.push_back(b + 1);
              end else begin
                if (code[b][j] == -1) R.delete(find(R, b + 1)); else if (code[b][j] == 0) L.push_back(b + 1);
              end
            end
            out[j] = s.weigh(L, R);
          end
          for (int b = 0; b < nb; b++) begin       // the code is the outcome (heavy) or its negation (light)
            match = 1; flip = 1;
            for (int j = 0; j < k; j++) begin
              if (code[b][j] != out[j]) match = 0;
              if (code[b][j] != -out[j]) flip = 0;
            end
            if (match) return '{b + 1, 1};
            if (flip) return '{b + 1, 0};
          end
          return '{0, 0};
        endfunction

        function automatic int find(int q[$], int x);     // the index of x in q
          foreach (q[i]) if (q[i] == x) return i;
          return -1;
        endfunction
        ```

    === "Python"
        ```python title="find_odd_ball" linenums="1"
        from itertools import product

        S = {"left": 1, "right": -1, "equal": 0}

        def find_odd_ball(n, weigh):
            k = 2
            while (3 ** k - 3) // 2 < n:
                k += 1

            def correct(c):  # the first change between neighbours goes up by 1 (mod 3)
                i = next((i for i in range(k - 1) if c[i] != c[i + 1]), None)
                return i is not None and (c[i + 1] - c[i]) % 3 == 1

            # one representative per orbit: a correct code whose first digit is 1 (off the scale)
            leaders = [c for c in product(range(3), repeat=k) if c[0] == 1 and correct(c)]
            q, extra = -(-n // 3), -n % 3
            codes = []
            for c in leaders[:q]:
                codes += [tuple((d + s) % 3 - 1 for d in c) for s in (1, 2, 0)]  # first digits +1, -1, 0
            if extra == 1:
                codes.pop()          # drop the member that is off the scale in weighing 1
            elif extra == 2:
                del codes[-3:-1]     # drop the +1/-1 pair, they cancel in weighing 1
            ball = {b + 1: c for b, c in enumerate(codes)}

            out = []
            for j in range(k):
                L = [b for b, c in ball.items() if c[j] == 1]
                R = [b for b, c in ball.items() if c[j] == -1]
                if j:  # fix the pan counts with balls known to be genuine after weighing 1
                    genuine = [b for b, c in ball.items() if out[0] not in (c[0], -c[0])]
                    for g in genuine:
                        if len(L) == len(R):
                            break
                        big, small = (L, R) if len(L) > len(R) else (R, L)
                        if g in big:
                            big.remove(g)
                        elif g not in small:
                            small.append(g)
                out.append(S[weigh(L, R)])

            out = tuple(out)
            for b, c in ball.items():
                if c == out:
                    return b, "heavy"
                if c == tuple(-x for x in out):
                    return b, "light"
        ```

    #### למה זה נכון { .sol-proof }

    **החסם.** הצעד הראשון משתמש בשני חסמים. אחרי שקילה שנטתה, כל אחת מ-\( 2a \)
    האפשרויות צריכה וקטור משלה מתוך \( 3^{k-1} \), ומספר זוגי לא יכול להיות שווה למספר
    אי-זוגי. אחרי שקילה מאוזנת, \( M \) כדורים עם עזר נותנים \( 2M \) אפשרויות, והווקטור
    "הכול מאוזן" לא יכול לשמש אף אחת מהן, ולכן \( 2M \le 3^{k-1} - 1 \).

    **הבנייה מאוזנת.** כל מסלול שלם מוסיף כדור אחד לכל כף בכל שקילה. במסלול החלקי,
    השקילה הראשונה נשארת מאוזנת לפי הבחירה של מי שמשמיטים, ובשאר השקילות הכפות נבדלות
    לכל היותר בכדור אחד, שכדור תקין משלים. כדור תקין לא משנה אף תוצאה, ולכן וקטור
    התוצאות הוא \( c \) או \( -c \) של החריג, בדיוק כמו בסעיף ב.

    **בדיקה.** הקוד נבדק על כל המצבים (כל כדור, קל וכבד) לכל \( N \) מ-3 עד 364, ובכולם
    הוא מוצא את הכדור הנכון במספר השקילות המינימלי, והכפות שוות בכל שקילה.

    #### סיבוכיות { .sol-cost }

    ‏\( k = \lceil \log_3(2N + 3) \rceil = O(\log N) \) שקילות. בניית הקודים עוברת על
    \( 3^k = O(N) \) קודים באורך \( k \), והשקילות והפענוח עוברים על \( N \) כדורים בכל
    אחת מ-\( k \) השקילות, ולכן הזמן הכולל הוא \( O(N \log N) \).

    - **מה קורה אם יצאה תוצאה שאין לה קוד?** בסעיף ב יש שלושה וקטורים כאלה :
      \( (0, 0, 0) \) והזוג \( \pm(1, -1, 1) \) שלא נבחר. הם מעידים על טעות בשקילה, או
      שאין כדור חריג בכלל.
    - **ואם יודעים מראש שהחריג כבד?** אז כל תוצאה מזהה כדור בלי סוג, ו-\( k \) שקילות
      מספיקות ל-\( 3^k \) כדורים : שלושה שלישים, ובכל שקילה נשאר השליש החשוד.
    - **ואם יש כדור תקין נוסף מראש?** אז אין צורך שהשקילה הראשונה תהיה מאוזנת בעצמה,
      ו-\( k \) שקילות מספיקות ל-\( \frac{3^k - 1}{2} \) כדורים, 13 בשלוש שקילות.
