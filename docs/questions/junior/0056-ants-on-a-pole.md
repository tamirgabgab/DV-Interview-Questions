## השאלה

על מוט באורך 100 ס"מ עומדות נמלים, כל אחת בנקודה אחרת (מספר שלם של ס"מ מהקצה השמאלי).
כל נמלה פונה ימינה או שמאלה והולכת במהירות של 1 ס"מ לשנייה. כששתי נמלים נפגשות, שתיהן
מסתובבות מיד וממשיכות לכיוון ההפוך. נמלה שמגיעה לקצה המוט נופלת. הנמלים הן נקודות.

- **סעיף א – הנמלה האחרונה :** על המוט 100 נמלים, במקומות ובכיוונים כלשהם. מה הזמן הארוך
  ביותר שיכול לעבור עד שכולן נופלות?
- **סעיף ב – התנגשויות :** כמה התנגשויות יהיו בסידור נתון? ומה המספר הגדול ביותר האפשרי
  עם 100 נמלים?
- **סעיף ג – נמלה מסוימת :** מתי, ומאיזה צד, נופלת הנמלה ה-\( k \) משמאל? בדוגמה יש שש
  נמלים, במקומות 10, 25, 40, 60, 75 ו-90, שהולכות ימינה, שמאלה, ימינה, שמאלה, שמאלה
  וימינה. איזו נופלת אחרונה, ומתי?

??? interviewer "מה המראיין בודק"
    - **שינוי נקודת מבט :** האם המועמד מפסיק לעקוב אחרי התנגשויות אחת אחת, ומחפש תיאור שבו
      הן לא משנות כלום.
    - **מה נשמר :** האם הוא שם לב לשני דברים שלא משתנים : קבוצת המקומות, וסדר הנמלים לאורך
      המוט.
    - **ספירה :** האם הוא מתרגם את ההתנגשויות לזוגות, ומוצא מתי זוג נפגש.
    - **מקרי קצה :** נמלה בקצה המוט, ונמלים שנפגשות בחצי סנטימטר.

### סעיף א – מתי הנמלה האחרונה נופלת

??? tip "רמז 1"
    שתי נמלים נפגשות ומסתובבות. איך זה נראה למי שלא רואה איזו נמלה היא איזו?

??? tip "רמז 2"
    נניח שהנמלים פשוט עוברות זו דרך זו. כמה זמן לוקח לכל אחת ליפול?

<div class="selfcheck" data-answer="100" data-show="100 שניות" data-hint="כל רוח הולכת ישר עד הקצה שמולה, ולכן היא נופלת אחרי לכל היותר 100 שניות. ונמלה בקצה השמאלי שפונה ימינה צריכה בדיוק 100." markdown>
מה הזמן הארוך ביותר, בשניות, עד שכל 100 הנמלים נופלות?
</div>

??? success "פתרון סעיף א"
    !!! answer "תשובה בקצרה"
        ‏100 שניות, לא משנה כמה נמלים יש. התנגשות נראית בדיוק כמו שתי נמלים שעוברות זו דרך
        זו, ולכן כל "רוח" הולכת ישר עד הקצה ונופלת אחרי \( p \) או \( 100 - p \) שניות. הזמן
        האחרון הוא המקסימום של המספרים האלה, ו-100 מתקבל כשנמלה עומדת בקצה ופונה פנימה.

    #### הרעיון { .sol-idea }

    **לשכוח את השמות.** כששתי נמלים נפגשות בנקודה \( x \) ומסתובבות, ברגע הבא יש נמלה אחת
    שהולכת שמאלה מ-\( x \) ונמלה אחת שהולכת ימינה מ-\( x \). אם הן היו עוברות זו דרך זו,
    היינו רואים בדיוק את אותו דבר : שתי נקודות באותם מקומות, באותם כיוונים. ההבדל היחיד הוא
    **איזו** נמלה נמצאת בכל נקודה.

    **רוחות.** לכן אפשר לדמיין "רוחות" שעוברות זו דרך זו בלי להסתובב. בכל רגע, קבוצת המקומות
    של הנמלים זהה לקבוצת המקומות של הרוחות. רוח שמתחילה ב-\( p \) והולכת שמאלה יוצאת מהמוט
    אחרי \( p \) שניות, ורוח שהולכת ימינה יוצאת אחרי \( 100 - p \). המוט מתרוקן כשהרוח
    האחרונה יוצאת.

    בתרשים, המקום הוא הציר האופקי והזמן יורד למטה. מימין הנמלים האמיתיות, כל אחת בצבע שלה,
    בקווים שבורים. משמאל הרוחות, בקווים ישרים. אלה **אותם קווים בדיוק**, רק הצבעים מתחלפים
    בכל מפגש :

    #### השלבים { .sol-steps }

    <div class="steps" markdown>

    1. **לכל נמלה, הזמן של הרוח שלה :** ‏\( p \) אם היא פונה שמאלה, ‏\( 100 - p \) אם ימינה.
    2. **התשובה לסידור נתון :** המקסימום של הזמנים האלה. בדוגמה של סעיף ג : ‏\( \max(25, 60,
       75, 90, 60, 10) = 90 \).
    3. **הגרוע ביותר :** כל זמן הוא לכל היותר 100, ו-100 מתקבל רק כשיש נמלה ב-0 שפונה
       ימינה או ב-100 שפונה שמאלה.

    </div>

    #### הקוד { .sol-code }

    === "SystemVerilog"
        ```systemverilog title="function last_fall" linenums="1" hl_lines="5"
        // the ghosts walk through each other: the pole is empty when the last ghost is off
        function automatic int last_fall(int pos[], int dirs[], int len = 100);
          int best = 0;
          foreach (pos[i]) begin
            int t = (dirs[i] < 0) ? pos[i] : len - pos[i];   // (1)!
            if (t > best) best = t;
          end
          return best;
        endfunction
        ```

        1. הזמן של הרוח : עד הקצה השמאלי אם היא פונה שמאלה, עד הימני אם ימינה.

    === "Python"
        ```python title="last_fall" linenums="1" hl_lines="3"
        def last_fall(pos: list[int], dirs: list[int], length: int = 100) -> int:
            """When the last ant falls; dirs: +1 right, -1 left; speed 1."""
            return max(p if d < 0 else length - p for p, d in zip(pos, dirs))   # (1)!
        ```

        1. כל רוח יוצאת אחרי \( p \) או \( 100 - p \) שניות, והמוט מתרוקן עם האחרונה.

    #### למה זה נכון { .sol-proof }

    **הנמלים והרוחות באותם מקומות.** בין שני מפגשים, נמלה ורוח זזות באותו אופן. במפגש בנקודה
    \( x \), שתי הנמלים מסתובבות ושתי הרוחות לא, אבל בשני המקרים יוצאות מ-\( x \) נקודה
    אחת שמאלה ונקודה אחת ימינה. לכן בכל רגע קבוצת המקומות (עם הכיוונים) זהה.

    **המוט מתרוקן יחד.** נמלה נופלת בקצה בדיוק כשרוח יוצאת ממנו באותו רגע, ולכן המוט מתרוקן
    מנמלים באותו רגע שבו הוא מתרוקן מרוחות.

    **מספר הנמלים לא משנה.** עם 100 נמלים או עם אחת, הזמן הוא לכל היותר 100 שניות, כי כל
    רוח צריכה לכל היותר את כל המוט.

### סעיף ב – כמה התנגשויות

??? tip "רמז 1"
    כל התנגשות של נמלים היא מפגש של שתי רוחות. אילו זוגות של רוחות נפגשים?

??? tip "רמז 2"
    שתי רוחות נפגשות רק אם הן הולכות זו לקראת זו : השמאלית ימינה והימנית שמאלה. ואז הן
    תמיד נפגשות, לפני שאחת מהן יוצאת.

<div class="selfcheck" data-answer="2500" data-show="2500 = 50 · 50" data-hint="כל נמלה שהולכת ימינה פוגשת כל נמלה שהולכת שמאלה ונמצאת מימינה. כמה זוגות כאלה יש לכל היותר, כש-k הולכות ימינה ו-100 − k שמאלה?" markdown>
מה המספר הגדול ביותר של התנגשויות עם 100 נמלים?
</div>

??? success "פתרון סעיף ב"
    !!! answer "תשובה בקצרה"
        מספר הזוגות שבהם נמלה שהולכת ימינה נמצאת משמאל לנמלה שהולכת שמאלה. כל זוג כזה נפגש
        פעם אחת בדיוק, וזוגות אחרים אף פעם. בדוגמה של סעיף ג יש 5. הכי הרבה : 50 נמלים
        בצד שמאל הולכות ימינה ו-50 בצד ימין הולכות שמאלה, ‏\( 50 \cdot 50 = 2500 \).

    #### הרעיון { .sol-idea }

    בתרשים של סעיף א, כל התנגשות היא נקודה שבה שני קווים נחתכים, ואותם חיתוכים בדיוק יש
    בין הקווים הישרים של הרוחות. שני קווים ישרים נחתכים רק אם הם הולכים זה לקראת זה. לכן
    סופרים זוגות : לכל נמלה שהולכת שמאלה, כמה נמלים שהולכות ימינה נמצאות משמאלה. בדוגמה :

    <!-- gen 2 -->

    | נמלה שהולכת שמאלה | הנמלות שהולכות ימינה משמאלה | התנגשויות |
    |:-:|:-:|:-:|
    | ‏25 | ‏10 | ‏1 |
    | ‏60 | ‏10, 40 | ‏2 |
    | ‏75 | ‏10, 40 | ‏2 |
    | **סך הכול** | | **‏5** |

    <!-- /gen -->

    #### השלבים { .sol-steps }

    <div class="steps" markdown>

    1. **סדר :** עוברים על הנמלים משמאל לימין.
    2. **מונה :** סופרים כמה נמלים שהולכות ימינה כבר עברנו.
    3. **צבירה :** כל נמלה שהולכת שמאלה תתנגש בכולן, ולכן מוסיפים את המונה לסכום.
    4. **הכי הרבה :** עם \( k \) שהולכות ימינה, לכל היותר \( k(n - k) \) זוגות, והמקסימום
       ב-\( k = n/2 \) : ‏\( \lfloor n^2 / 4 \rfloor \).

    </div>

    #### הקוד { .sol-code }

    === "SystemVerilog"
        ```systemverilog title="function collisions" linenums="1" hl_lines="6"
        // pos ascending: every ant going left meets every ant going right on its left
        function automatic int collisions(int pos[], int dirs[]);
          int count = 0, right = 0;
          foreach (dirs[i])
            if (dirs[i] > 0) right++;
            else count += right;                    // (1)!
          return count;
        endfunction
        ```

        1. הרוח הזאת פוגשת את כל הרוחות שהולכות ימינה ונמצאות משמאלה.

    === "Python"
        ```python title="collisions" linenums="1" hl_lines="8"
        def collisions(pos: list[int], dirs: list[int]) -> int:
            """How many times two ants meet: the pairs going toward each other."""
            count = right = 0
            for p, d in sorted(zip(pos, dirs)):
                if d > 0:
                    right += 1
                else:
                    count += right                  # (1)!
            return count
        ```

        1. הרוח הזאת פוגשת את כל הרוחות שהולכות ימינה ונמצאות משמאלה.

    #### למה זה נכון { .sol-proof }

    **כל זוג נפגש פעם אחת, או אף פעם.** שתי רוחות באותו כיוון לא נפגשות. רוח שהולכת ימינה
    מ-\( a \) ורוח שהולכת שמאלה מ-\( b > a \) נפגשות אחרי \( (b - a)/2 \) שניות, וזה לפני
    ששתיהן יוצאות : ‏\( (b - a)/2 < 100 - a \) ו-\( (b - a)/2 < b \). אם \( b < a \) הן מתרחקות.

    **מפגש של רוחות הוא התנגשות.** כשהרוחות נפגשות, שתי נמלים נמצאות באותה נקודה, ולכן הן
    מתנגשות. ולהפך : כל התנגשות היא שתי נמלים באותה נקודה, כלומר שתי רוחות.

    **המקסימום.** ‏\( k \) נמלים שהולכות ימינה ו-\( n - k \) שמאלה נותנות לכל היותר
    \( k(n - k) \) זוגות, וזה מתקבל כשכל ההולכות ימינה משמאל לכל ההולכות שמאלה. ‏\( k(n - k) \)
    מקסימלי ב-\( k = n/2 \).

### סעיף ג – מתי נופלת נמלה מסוימת

??? tip "רמז 1"
    נמלים לא עוברות זו את זו. מה זה אומר על הסדר שבו הן נופלות מהקצה השמאלי?

??? tip "רמז 2"
    ספרו כמה רוחות יוצאות משמאל. בדיוק אותו מספר של נמלים נופל משמאל, ואלה הנמלים הכי
    שמאליות.

בדוגמה של שש הנמלים, אחרי כמה שניות נופלת האחרונה?

??? success "פתרון סעיף ג"
    !!! answer "תשובה בקצרה"
        הסדר לאורך המוט לא משתנה. אם \( \ell \) נמלים הולכות שמאלה, ‏\( \ell \) הנמלים השמאליות
        נופלות שמאלה, והנמלה ה-\( k \) משמאל נופלת בזמן ה-\( k \) בגודלו מבין \( p \) של
        ההולכות שמאלה. השאר נופלות ימינה, הימנית ביותר ראשונה. בדוגמה האחרונה היא הרביעית
        (התחילה ב-60), אחרי 90 שניות.

    <!-- cost: זמן \( O(n \log n) \) | זיכרון \( O(n) \) -->

    #### הרעיון { .sol-idea }

    **הסדר נשמר.** נמלים לא עוברות זו את זו : הן רק נפגשות ומסתובבות. לכן הנמלה הכי שמאלית
    נשארת הכי שמאלית, וכן הלאה.

    **מי נופל משמאל.** הרוחות שיוצאות משמאל הן בדיוק אלה שהולכות שמאלה, ובכל פעם שרוח יוצאת
    משמאל נופלת הנמלה השמאלית ביותר שעוד על המוט. לכן אם \( \ell \) רוחות הולכות שמאלה,
    ‏\( \ell \) הנמלים השמאליות נופלות שמאלה, לפי הסדר, בזמנים של הרוחות האלה מהקטן לגדול.
    בצד ימין אותו דבר, מהנמלה הימנית ביותר.

    **הדוגמה.** שלוש רוחות הולכות שמאלה, מ-25, 60 ו-75. לכן נמלים 1, 2 ו-3 נופלות שמאלה
    אחרי 25, 60 ו-75 שניות. הרוחות שהולכות ימינה, מ-10, 40 ו-90, יוצאות אחרי 90, 60 ו-10
    שניות. לכן נמלה 6 נופלת ראשונה מימין (10), נמלה 5 אחריה (60), ונמלה 4 אחרונה (90). זו
    התשובה : הנמלה שהתחילה ב-60, והתחילה ללכת **שמאלה**, נופלת אחרונה **מימין**.

    #### השלבים { .sol-steps }

    <div class="steps" markdown>

    1. **הזמנים משמאל :** ‏\( p \) של כל ההולכות שמאלה, ממוינים מהקטן לגדול.
    2. **הזמנים מימין :** ‏\( 100 - p \) של כל ההולכות ימינה, ממוינים מהגדול לקטן.
    3. **שרשור :** הרשימה הראשונה ואחריה השנייה היא זמן הנפילה של הנמלים לפי הסדר משמאל.

    </div>

    #### הקוד { .sol-code }

    === "SystemVerilog"
        ```systemverilog title="function fall_times" linenums="1" hl_lines="7 8 9"
        // pos ascending; t[k] is when the k-th ant from the left falls
        function automatic void fall_times(int pos[], int dirs[], int len, ref int t[$]);
          int left[$], right[$];
          foreach (pos[i])
            if (dirs[i] < 0) left.push_back(pos[i]);
            else             right.push_back(len - pos[i]);
          left.sort();                              // (1)!
          right.rsort();                            // (2)!
          t = {left, right};
        endfunction
        ```

        1. הנמלים השמאליות נופלות משמאל, לפי הסדר, בזמני הרוחות שהולכות שמאלה מהקטן לגדול.
        2. מימין הנמלה הימנית ביותר נופלת ראשונה, ולכן מהגדול לקטן כשסופרים משמאל.

    === "Python"
        ```python title="fall_times" linenums="1" hl_lines="3 4 5"
        def fall_times(pos: list[int], dirs: list[int], length: int = 100) -> list[int]:
            """When each ant falls, the ants in their order along the pole (pos ascending)."""
            left = sorted(p for p, d in zip(pos, dirs) if d < 0)            # (1)!
            right = sorted(length - p for p, d in zip(pos, dirs) if d > 0)
            return left + right[::-1]                                        # (2)!
        ```

        1. הזמנים של הרוחות שיוצאות משמאל, ושל אלה שיוצאות מימין.
        2. השמאליות קודם, מהזמן הקטן; מימין הסדר הפוך, כי הנמלה הימנית ביותר נופלת ראשונה.

    #### למה זה נכון { .sol-proof }

    **הסדר נשמר.** שתי נמלים שכנות יכולות רק להיפגש ולהסתובב, לא לעבור זו את זו. לכן בכל
    רגע הנמלים על המוט, משמאל לימין, הן אותן נמלים באותו סדר.

    **מי נופל משמאל.** ברגע שרוח יוצאת משמאל, נמלה נופלת משמאל (סעיף א), והיא הנמלה
    השמאלית ביותר שעוד על המוט. לכן הנמלה ה-\( k \) משמאל נופלת עם הרוח ה-\( k \) שיוצאת
    משמאל, כל עוד \( k \le \ell \). אותו טיעון מימין.

    **נסו בעצמכם.** לוחצים על המוט כדי להוסיף נמלה, ולוחצים על נמלה כדי להפוך את הכיוון שלה
    (לחיצה שנייה מוחקת אותה). המתג מחליף בין נמלים שמסתובבות לרוחות שעוברות זו דרך זו :
    המקומות זהים, רק הצבעים מתחלפים. מתחת למוט התרשים של מקום מול זמן מצטייר בזמן ההרצה :

## נקודות חשובות ושאלות המשך

??? trap "מלכודת : לסמלץ התנגשות אחרי התנגשות"
    עם 100 נמלים יכולות להיות 2500 התנגשויות, וקל לטעות בסדר שלהן. הטריק של הרוחות מבטל את
    הצורך לעקוב אחריהן : הזמן תלוי רק במקום ובכיוון של כל נמלה לבד.

??? trap "מלכודת : 'הנמלה נופלת מהצד שאליו היא פונה'"
    בדוגמה, הנמלה שהתחילה ב-60 פונה שמאלה, אבל נופלת מימין, אחרונה. מה שהולך ישר הוא הרוח,
    לא הנמלה : הנמלה מקבלת את הזמן של רוח אחרת.

??? trap "מלכודת : להוסיף זמן על כל התנגשות"
    הסתובבות לא לוקחת זמן, ולכן הזמן הכולל לא גדל עם מספר ההתנגשויות. אם כל סיבוב לוקח
    זמן, הטריק לא עובד כמו שהוא.

??? followup "שאלות המשך"
    - **כיוונים אקראיים :** כל נמלה פונה ימינה או שמאלה בהסתברות חצי. מה תוחלת מספר ההתנגשויות?

        ??? fu-answer "תשובה"
            כל זוג נפגש אם השמאלית הולכת ימינה והימנית שמאלה, בהסתברות 1/4. לכן התוחלת
            \( \binom{n}{2} / 4 = n(n - 1)/8 \) : ל-100 נמלים 1237.5.

    - **גם המקומות אקראיים :** המקומות אחידים על המוט. מה תוחלת הזמן עד שהמוט מתרוקן?

        ??? fu-answer "תשובה"
            הזמן של כל רוח אחיד בין 0 ל-100, בלתי תלוי באחרות, והתשובה היא המקסימום של \( n \)
            משתנים כאלה : ‏\( 100 \cdot n / (n + 1) \) שניות.

    - **מסלול מעגלי :** הנמלים על מעגל באורך 100, בלי קצוות. מה קורה אחרי 100 שניות?

        ??? fu-answer "תשובה"
            כל רוח השלימה סיבוב, ולכן קבוצת המקומות זהה להתחלה. הסדר המעגלי נשמר, ולכן כל נמלה
            עומדת במקום של נמלה אחרת : הסידור הסתובב במספר מקומות שתלוי בהפרש בין ההולכות ימינה
            לשמאלה.

    - **מהירויות שונות :** האם הטריק עובד כשלכל נמלה מהירות משלה?

        ??? fu-answer "תשובה"
            רק אם בהתנגשות הנמלים מחליפות מהירויות (כמו כדורים שמתנגשים), ואז הרוחות עדיין
            עוברות זו דרך זו. אם כל אחת שומרת את המהירות שלה ורק מסתובבת, הטריק נשבר.
