# תכנון לוגיקה

שמונה שאלות שבונות זו על זו : פלופ ושער, מכונות מצבים, מונה עם פלופ בירידת השעון, רגיסטר הזזה עם משוב, בורר, ומעגל אריתמטי שמחשב שורש ריבועי ביט אחרי ביט. בכל אחת יש קוד SystemVerilog, מודל Python ודיאגרמת תזמון.
