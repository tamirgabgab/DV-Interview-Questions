# מסלולי לימוד

כל מסלול הוא כמה שאלות באותו נושא, בסדר שבו כדאי לפתור אותן : כל שאלה מכינה את הכלים לשאלה
שאחריה. בראש כל שאלה במסלול יש קישורים לשאלה הקודמת ולבאה, ובדף המסלול רואים כמה שאלות
כבר סימנתם כפתורות.

כל קו במפה הוא מסלול, וכל תחנה היא שאלה לפי הסדר שלה במסלול. שאלה שנמצאת בכמה מסלולים היא
תחנת מעבר שבה הקווים נפגשים. לחיצה על תחנה פותחת את השאלה, ותחנה שסימנתם כפתורה מתמלאת בצבע
הקו.
