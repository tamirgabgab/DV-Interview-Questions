# פרוטוקולים, מפיצול אחד למודלי ייחוס

שלוש השאלות הראשונות עוסקות באותם שלושה פרמטרים, MRRS, ‏MPS ו-RCB : הראשונה מתרגמת את חוקי ה-SPEC לתנאי אחד ומונה פיצולים, השנייה סופרת אותם ומוכיחה נוסחה, והשלישית בונה מודל ייחוס של Endpoint. שתי האחרונות בונות מודלי ייחוס לעוד שני מנגנונים של פרוטוקול : שידור חוזר ב-PCIe ובקרת זרימה ב-USB4.
