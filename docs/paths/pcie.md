# מסלול PCIe, מפיצול אחד למודל ייחוס

שלוש שאלות על אותם שלושה פרמטרים, MRRS, ‏MPS ו-RCB. השאלה הראשונה מתרגמת את חוקי
ה-SPEC לתנאי אחד ומונה פיצולים, השנייה סופרת אותם ומוכיחה נוסחה, והשלישית בונה מודל
ייחוס של Endpoint שמייצר אותם בתוך סביבת אימות.
